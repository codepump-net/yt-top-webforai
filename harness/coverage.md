300KB와 40개는 프로젝트 점검 유도 기준이며 검색엔진의 순위 임계값이 아니다. CSS 배경·외부 번들·이미지 전송량을 모두 포함하지 않는다.

`audit`는 기존 `audit.cjs` 출력 형식용이다. 실시간 수집이나 일반적인 웹 취약점 검사가 아니다. 의료적 타당성·실제 색인·실사용 성능·AI 인용 성과는 자동 통과 항목으로 표시하지 않는다.
