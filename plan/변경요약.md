# 변경 요약

## 1. 상단 메뉴

최종 순서는 다음과 같습니다.

```text
증상백과
질환백과
진료분야
검사·시술
암환자 지지치료
검진·서류
병원안내
공지사항
```

공지사항은 병원안내 하위 링크가 아니라 상단 독립 메뉴입니다.

## 2. 암환자 카테고리 명칭

사용자에게 보이는 모든 위치에서 다음과 같이 통일합니다.

```text
암환자 지지진료 → 암환자 지지치료
암 치료 중 지지진료 → 암 치료 중 지지치료
지지진료 → 지지치료
```

기존 URL `/services/cancer-support/`와 내부 ID는 외부 링크 손실을 막기 위해 유지합니다.

## 3. 공지사항 게시판

표시 열:

```text
번호 | 제목 | 게시일 | 조회수
```

기능:

- 제목·태그 검색
- 공지 분류 필터
- 중요 공지 상단 고정
- 페이지 이동
- 모바일 카드형 전환
- 개별 상세 URL

GitHub Pages만으로는 전체 방문자의 누적 조회수를 저장할 수 없으므로 기본값은 데이터의 `views`를 표시합니다. 실제 전역 조회수는 선택형 외부 API를 연결합니다.

## 4. 인플루엔자 일정

2026–2027절기 국가예방접종 글에는 대상별 시작일·종료일·확인사항을 한눈에 볼 수 있는 HTML 표를 추가합니다.

## 5. 감염병 예방 가이드

제목은 다음 문구를 그대로 사용합니다.

> 질병관리청 최신 데이터(9.17 기준)로 보는 우리 가족 감염병 예방 가이드

업로드한 PDF의 15쪽을 1쪽부터 15쪽까지 이미지로 그대로 표시합니다. 별도의 모델 요약문으로 대체하지 않습니다.

## 6. 이미지 화질

17개 대표 배너·안내도를 최초 생성 PNG 원본으로 교체합니다.

- 별도 압축 WebP를 대표 노출에 사용하지 않음
- 원본 비율 유지
- 원본 픽셀 폭보다 크게 확대하지 않음
- 클릭 시 원본 PNG 표시
- 새 경로 `/assets/clinic-visuals-hq/`
- 새 파일명 `*-hq-original.png`로 캐시 충돌 방지
