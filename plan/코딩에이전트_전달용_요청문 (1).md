# 코딩에이전트 전달용 요청문

첨부한 `영통탑내과_2026-09-29_최신대화내용_블로그통합이식패키지`를 현재 블로그 저장소에 적용해 주세요.

## 필수 요구사항

1. 패키지의 `03_통합스크립트/apply-all-2026-09-29-latest.mjs`를 사용해 두 모듈을 순서대로 적용합니다.
2. 상단 메뉴는 다음 순서로 맞춥니다.
   - 증상백과
   - 질환백과
   - 진료분야
   - 검사·시술
   - 암환자 지지치료
   - 검진·서류
   - 병원안내
   - 공지사항
3. `암환자 지지진료`, `암 치료 중 지지진료`, `지지진료`가 사용자에게 보이는 곳에 남지 않도록 `지지치료`로 교체합니다. 기존 URL은 유지합니다.
4. 공지사항은 번호·제목·게시일·조회수와 검색·분류·페이지 이동이 있는 게시판으로 렌더링합니다.
5. 인플루엔자 공지에 대상별 접종일정 HTML 표를 표시합니다.
6. 감염병 공지 제목을 정확히 `질병관리청 최신 데이터(9.17 기준)로 보는 우리 가족 감염병 예방 가이드`로 사용합니다.
7. 해당 공지에는 첨부 PDF 15쪽을 순서대로 이미지로 게시하고, 별도의 임의 요약문으로 대체하지 않습니다.
8. 17개 대표 배너·안내도는 `/assets/clinic-visuals-hq/*-hq-original.png`의 원본 PNG를 사용합니다.
9. 이미지를 자르거나 원본 크기보다 확대하지 말고, 클릭하면 원본을 열 수 있게 합니다.
10. 공식 채널을 홈페이지 방문 안내 영역과 전역 푸터에 연결합니다.
    - https://yttop.co.kr/
    - https://blog.naver.com/goytt2022
    - https://www.instagram.com/yttopim
11. MedicalClinic/Organization JSON-LD의 `sameAs`에도 세 주소를 넣습니다.
12. 기존 푸터의 단독 홈페이지 링크가 새 채널 영역과 중복되면 제거합니다.
13. 빌드 후 통합 검증 스크립트를 `--strict-ui` 옵션으로 실행합니다.
14. 최종 결과에서 변경 파일 목록, 빌드 결과, 남은 경고를 보고해 주세요.
