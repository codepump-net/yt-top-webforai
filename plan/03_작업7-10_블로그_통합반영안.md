# 작업 7-10 블로그 통합 반영안

## A. 공통 하단 안내문

`01_공통_하단_안내문_및_적용규칙.md`를 기준으로 공통 컴포넌트를 구현합니다.

권장 컴포넌트 구조:

```tsx
<ArticleFooter
  clinicInfo
  medicalSafety
  heartReservation={category === "심장·혈관" || section === "heart-tests"}
  documentNotice={section === "checkups-documents"}

```

중복 방지를 위해 본문별 수기 입력보다 메타데이터에 따른 자동 삽입을 권장합니다.

## B. 심장·혈관 질환백과 20편

업로드한 Word 원고 20편을 `질환백과 → 심장·혈관`에 반영합니다.

### 반영하면서 수정한 병원 사실

- Troponin I, CK-MB, Troponin T, CPK, D-dimer, NT-proBNP 시행 가능
- Troponin I: 원내 약 20분
- 나머지 검사: 일반적으로 다음 날
- IMA: 향후 도입 예정, 현재 시행 검사로 표시하지 않음
- CART BP Pro 반지형 24시간 활동혈압검사: 장비 반납 후 약 1시간 내 결과 확인
- 모든 20편에 병원 공통 안내, 안전 안내, 심장검사 예약 안내 삽입
- 최종 검토일 2026-09-26로 통일

### 기존 페이지와 중복 처리

- `협심증의 약물치료와 스텐트`는 안정형 협심증 질환페이지의 **관련 FAQ 글**로 유지합니다.
- `심장판막 역류와 치료·추적검사`는 승모판 역류·대동맥판 협착 질환페이지의 **관련 해설 글**로 유지합니다.
- `심장질환 진료`는 질환백과 항목이 아니라 **진료분야 허브**로 유지합니다.
- 기존 글을 새 질환페이지와 합치지 않고 동일한 검색의도를 가진 중복 페이지로 만들지 않습니다.

## C. 증상백과 카테고리

최종 표시 순서:

1. 심장·혈관
2. 속쓰림·소화불량·급·만성 복통
3. 간·췌장·담도·쓸개
4. 당뇨·갑상선·고지혈증
5. 호흡기·감염
6. 신장
7. 암 치료 중 증상

### 현재 증상백과에서 이동할 비증상 페이지

- `심장질환 진료` → 진료분야
- `혈압·당뇨·고지혈증과 생활관리` → 진료분야
- `호흡기·감염질환 진료` → 진료분야
- `급성 증상과 응급 진료 안내` → 진료분야 또는 응급안내 허브

증상백과에는 실제 증상 질문형 글만 노출하는 것을 원칙으로 합니다.

## D. 질환백과 카테고리

최종 표시 순서:

1. 소화기(위·대장·간·담도·췌장)
2. 호흡기·감염
3. 심장·혈관
4. 암과 가족력
5. 내분비·대사·갑상선

### 질환백과에서 이동할 비질환 페이지

- `만성기침 진료` → 증상백과 또는 진료분야
- `암 치료 중 증상별 대처와 위험 신호` → 암환자 지지진료
- `혈압·당뇨·고지혈증과 생활관리` → 진료분야
- `호흡기·감염질환 진료` → 진료분야
- `심장질환 진료` → 진료분야

실제 질환명 페이지와 FAQ·검사·진료분야 글을 분리해 검색의도를 명확히 합니다.

## E. 검색·사이트맵·내부 링크

- 20개 심장·혈관 질환 URL을 사이트 검색, HTML 전체 페이지, XML 사이트맵에 자동 포함
- 질환페이지마다 관련 증상 3-5개, 관련 검사 2-4개, 관련 FAQ 1-3개 연결
- 증상페이지에서는 가능한 원인으로 질환페이지를 연결
- 구 카테고리명은 검색 동의어로 남기되 화면에는 새 이름만 표시
- 카테고리 필터 수치(전체 글 수)를 실제 데이터에서 자동 계산

## F. 공개 전 검토

- 심장 관련 혈액검사 문구가 Troponin I만 가능한 것처럼 남아 있지 않은지 검색
- `BNP 외부검사` 등 오래된 표현 제거
- IMA는 `향후 도입 예정`으로만 표시
- 24시간 혈압검사에 CART BP Pro, 24시간 착용, 반납 후 약 1시간 결과 확인 표기
- 각 글 하단 공통 패널이 한 번만 출력되는지 확인
- 작성·의학적 검토자와 최종 검토일 확인
