# 최종 검수 체크리스트

## 메뉴와 명칭

- [ ] 데스크톱 상단 메뉴에 `공지사항`이 독립 항목으로 표시된다.
- [ ] 모바일 메뉴에도 `공지사항`이 표시된다.
- [ ] 상단 메뉴 순서가 확정안과 일치한다.
- [ ] 사용자 화면에서 `암환자 지지진료`가 남아 있지 않다.
- [ ] 모든 관련 제목·본문·메타·검색·관련글이 `지지치료`를 사용한다.
- [ ] 기존 `/services/cancer-support/` URL은 유지된다.

## 공지사항 게시판

- [ ] 번호·제목·게시일·조회수 열이 보인다.
- [ ] 제목·태그 검색이 작동한다.
- [ ] 분류 필터가 작동한다.
- [ ] 중요 공지가 상단에 고정된다.
- [ ] 페이지 이동이 작동한다.
- [ ] 모바일에서는 읽기 쉬운 카드형 또는 반응형 표로 보인다.
- [ ] 각 공지가 독립 상세 URL을 가진다.

## 인플루엔자 공지

- [ ] 대상별 시작일 표가 HTML로 표시된다.
- [ ] 표가 모바일에서 가로 스크롤 또는 카드형으로 읽힌다.
- [ ] 공식 출처와 확인일이 표시된다.

## 감염병 안내

- [ ] 제목이 정확히 `질병관리청 최신 데이터(9.17 기준)로 보는 우리 가족 감염병 예방 가이드`이다.
- [ ] 15개 이미지가 1쪽부터 15쪽까지 빠짐없이 표시된다.
- [ ] 각 페이지 이미지가 잘리거나 순서가 바뀌지 않았다.
- [ ] 클릭하면 원본 크기로 볼 수 있다.
- [ ] 별도의 임의 요약문이 원문 이미지를 대체하지 않는다.
- [ ] 원본 PDF 링크가 정상 작동한다.

## 이미지 원본 화질

- [ ] 17개 자산이 모두 `/assets/clinic-visuals-hq/`에 있다.
- [ ] 네트워크 요청 파일명이 `-hq-original.png`이다.
- [ ] 기존 저화질 WebP가 대표 화면에 사용되지 않는다.
- [ ] 이미지가 원본 비율을 유지한다.
- [ ] `object-fit: cover`로 잘리지 않는다.
- [ ] 원본 픽셀 폭보다 크게 확대되지 않는다.
- [ ] 클릭 시 원본 PNG가 열린다.
- [ ] ALT 문구가 유지된다.

## 공식 채널

- [ ] 홈페이지에 병원 홈페이지 카드가 있다.
- [ ] 홈페이지에 네이버 블로그 카드가 있다.
- [ ] 홈페이지에 인스타그램 카드가 있다.
- [ ] 전역 푸터에 세 링크가 있다.
- [ ] 새 창과 `noopener noreferrer external`이 적용된다.
- [ ] JSON-LD `sameAs`에 세 URL이 있다.
- [ ] 기존 단독 홈페이지 링크가 불필요하게 중복되지 않는다.

## 빌드·배포

- [ ] `npm run build`가 성공한다.
- [ ] 기본 검증 스크립트가 통과한다.
- [ ] `--strict-ui` 검증이 통과한다.
- [ ] 브라우저 하드 새로고침 후 최신 파일이 보인다.
- [ ] 운영 전 의료·문구 검토가 완료될 때까지 review/noindex를 유지한다.
