# 모의 적용·검증 보고서

## 시험 환경

실제 저장소를 변경하지 않고, 필요한 최소 파일 구조를 가진 임시 저장소에 통합 스크립트를 적용했습니다.

## 적용 결과

- 공지사항·지지치료·감염병 이미지 모듈: 정상 적용
- 원본화질 이미지·공식 채널 모듈: 정상 적용
- 공지 데이터: 6편 생성
- 고해상도 이미지 원장: 17개 연결
- 공식 채널: 3개 등록
- 감염병 안내 이미지: 15쪽 확인
- 인플루엔자 일정표 데이터: 확인
- 자동 검증 실패: 0개

## 예상 경고

기본 검증에서는 `OfficialChannels`가 홈페이지와 푸터에서 실제로 사용되는지에 대한 경고 1개가 남았습니다. 이는 저장소별 레이아웃 파일 위치가 달라 자동으로 안전하게 삽입하지 않은 항목입니다.

실제 저장소에서 다음 두 위치에 컴포넌트를 연결한 뒤 `--strict-ui` 검증을 실행하십시오.

```tsx
<OfficialChannels variant="visit" />
<OfficialChannels variant="footer" />
```

또한 MedicalClinic/Organization JSON-LD의 `sameAs`에 세 공식 채널을 병합해야 합니다.
