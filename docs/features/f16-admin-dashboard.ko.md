# F16. 운영자 대시보드

상태: **계획**. 현재 저장소에 실행 가능한 `admin/` 앱·DB·API·인증 배포가 없다. 관련: F13·F14·F15.

## 목적과 경계

인증된 운영자가 검색·AI 관측·기술 점검의 출처·기간·오류·갱신 상태를 확인한다. 환자 사이트와 별도 앱·배포·비밀 관리 경계를 사용한다. 환자 사이트의 메뉴·검색·원장·사이트맵에 관리 경로를 추가하지 않는다.

## 기존 계획 활용

[2026-10-16 상세 계획](../client-requests/aeo-geo-operations-plan-2026-10-16/README.ko.md), [데이터 계약](../client-requests/aeo-geo-operations-plan-2026-10-16/data-contracts.ko.md), [개발 작업](../client-requests/aeo-geo-operations-plan-2026-10-16/implementation-backlog.ko.md)을 선행 자료로 사용한다. 거기에 제시된 React·Vite·Workers·D1·Access·수집기는 **후보 설계**다. 요금·무료 한도·API 가용성은 착수 시 최신 공식 자료와 실제 계정으로 재확인한다.

## 착수 가능한 세로 단위

1. 로그인한 운영자만 합성 관측 자료를 열람하는 최소 화면·API.
2. F15의 기존 집계 로직을 사용한 파일 검증·중복 방지·출처 표시.
3. 미연결·미측정·빈 상태·오류·오래된 자료 표시.
4. 계정 권한이 확보된 출처부터 실제 읽기 연결.
5. 보관·백업·복원·권한·갱신 실패를 확인한 뒤 운영 시작.

## 제안 완료 조건

- AC01: 화면·API·미리보기·증거 파일 모두 인증 경계를 통과해야 접근한다.
- AC02: 공식 자료와 같은 속성·기간·분모의 숫자가 일치하고 미측정을 0으로 만들지 않는다.
- AC03: 중복 가져오기·재실행이 집계를 증가시키지 않고 출처를 추적할 수 있다.
- AC04: 실제 원문·토큰·백업은 공개 저장소와 공개 artifact에 저장되지 않는다.
- AC05: 환자용 경로·배포·공개 검증이 바뀌지 않고 방문자 추가 UI가 없다.

## 필요한 검증

인증 우회·API 계약·합성 입력·집계 대조·실제 권한·복원 검사를 구현과 함께 정의한다. 아직 존재하지 않는 검사 파일·배포 URL·완료일을 현재 상태로 기재하지 않는다. 새 예약·진료기록 기능은 이 관리 앱의 범위에도 자동 포함하지 않는다.
