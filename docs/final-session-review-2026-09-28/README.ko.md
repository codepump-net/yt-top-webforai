검토일: 2026-09-28. 기준 커밋: `e27a4c4a4309e5e4fc2adb0f9ae3acf7fddc5fbf`. 내부 검토 보고서.

**종합 판정은 ‘부분 달성’이다. 요청한 화면·페이지·탐색 기능은 대부분 구현됐고, 원본 이미지 복원도 완료됐다. 그러나 환자 질문에 충분히 답하는 문구 편집, 이미지와 본문 정보의 대응, 이번 개정본의 의료·운영 확인은 완료되지 않았다. AEO·GEO는 기술 기반을 갖춘 검토 단계이며, 최적화 완료나 실제 노출 성과를 주장할 근거는 없다.**

이전 보고서의 ‘개발 완료’와 이번 세션의 테스트 통과를 콘텐츠 품질까지 완료됐다는 뜻으로 해석하면 안 된다. 특히 문구 전수검토는 문제 목록을 만든 작업이었으며, 그 목록을 전부 수정한 작업은 아니었다.

현재 `plan/` 문서·경로 CSV·이미지 모음판, 최초 26개 작업 묶음, 후속 사용자 지시, 현재 소스와 실제 배포 페이지를 대조했다. 이번에 129개 경로(404 포함)를 다시 수집해 모두 기준 커밋의 HTML과 일치함을 확인했다. 설치·이식·통합 절차는 원장님 콘텐츠 요구의 달성 기준에서 제외했다. 배포 검증은 현재 검토 대상을 확정하는 근거로만 사용했다.

이미지 7번의 콩팥 그림에는 여전히 ‘심장질환’이라고 적혀 있다. 이는 후속 지시인 ‘제공한 그대로 사용’을 따라 보존한 원본 표기다. 원본 보존은 달성했지만 제목과 신장 페이지의 일치는 해결되지 않았다. 정정 방향이 정해지기 전 임의로 글자를 바꾸거나 새 그림을 생성할 대상은 아니다.

**AEO·GEO 평가**

여기서 AEO는 환자 질문에 정확하고 직접적으로 답하는 정도, GEO는 생성형 검색이 병원의 정보를 이해하고 근거를 추적할 수 있는 정도로 평가했다. 임의의 점수나 달성률을 만들지 않았다.

| 평가 축 | 확인된 강점 | 현재 판정 |
|---|---|---|
| 읽을 수 있는 페이지 구조 | 129개 경로 모두 정적 HTML, 고유 제목·설명, H1 1개, 자기 URL canonical 확인 | 기술 기반 갖춤 |
| 질문과 답의 일치 | FAQ 152개의 질문·답이 보이는 본문과 JSON-LD에서 일치 | 형식 충족. 회피적인 답변도 그대로 일치하므로 유용성 완료는 아님 |
| 환자가 필요한 답을 얻는가 | 검사별 설명·표·관련 링크 존재 | 부분 충족. 위 사례와 기존 검토 항목의 편집이 필요 |
| 병원 정보의 일관성 | 404를 제외한 128개 페이지가 동일한 병원 ID·병원명·전화 사용. 병원·의료진·검사·서비스 구조화 데이터 제공 | 기술 기반 갖춤. 실제 운영 정보의 최신성 검토는 별도 |
| 근거와 검토 책임 | 본문 229개 블록에 출처 ID 연결, 페이지 출처 279개 참조 중 확인일 191개 기록 | 근거 추적 구조 있음. 개별 의료 검토 기록과 reviewedBy 표시는 0건. 출처 개수는 주장 타당성을 보증하지 않음 |

| 콘텐츠의 구체성·독자성 | 본원 검사 종류·결과 안내 등 구체 정보 존재 | 반복 공통 문단과 문의 중심 안내가 병원별 유용성을 약화함 |
| 검색·AI 노출 가능 상태 | robots.txt는 접근 허용 | 129개 경로 모두 noindex, 공개 XML 사이트맵 URL 0개. 현재는 검색 공개 대기 상태 |

Google의 현재 공식 안내는 특별한 AI 파일이나 전용 구조화 데이터보다 유용하고 고유한 내용, 기술적 접근성, 사용자 경험을 강조한다. `llms.txt`는 Google 검색에서 필요하지 않으므로 현재 404인 것을 최적화 실패로 세지 않았다. 페이지 수나 구조화 데이터 수만으로 AEO·GEO 성공을 평가하지 않는다. [Google 생성형 AI 검색 최적화 안내](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide).

Google의 AI 검색 출처 링크에는 색인과 검색 스니펫 노출 자격이 필요하다. 따라서 현재 noindex 상태에서 ‘Google AI 검색 노출 준비가 완료됐다’고 보고할 수 없다. 이는 의료 검토 전 review/noindex를 유지하라는 요청에 따른 설정이다. 이 결과를 모든 AI 서비스가 페이지를 읽지 못한다는 뜻으로 일반화하지 않는다. [Google AI 검색 기술 요건](https://developers.google.com/search/docs/appearance/ai-features#technical-requirements).

또한 Google은 2026년 5월 FAQ 리치 결과 종료를 알렸고 6월 해당 문서를 제거했다. 현재 FAQ 구조화 데이터의 존재를 FAQ 검색 특수노출 보장이나 AEO 점수로 설명해서는 안 된다. 환자에게 유용한 질문·답변 자체는 계속 필요하다. [Google 공식 변경 기록](https://developers.google.com/search/updates#june-2026).

**남은 작업의 우선순위와 완료 기준**

1. **이미지와 HTML의 정보 차이부터 정리한다.** 5개 안내도를 본문과 대조하고 특히 준비·식사·활동·결과 안내의 조건을 맞춘다. 원본 이미지는 보존하고 핵심 정보를 읽을 수 있는 표·목록을 완성한다. 신장 배너 제목 오기는 별도 확인 항목으로 유지한다.
2. **이미 본문에 있는 답을 FAQ·도입에 반영한다.** 채용·결핵·비자검진, 검사 준비·결과 시간부터 처리한다. 질문에 대한 답, 적용 조건, 필요한 행동이 이어지도록 편집하고 FAQ 구조화 데이터도 함께 검증한다.
3. **증상 20편·질환 20편·공통 하단을 페이지별로 다시 읽는다.** 같은 마무리 문단, 질문과 무관한 방어 문구, 요구사항을 설명하는 문장을 줄이고 각 주제의 핵심 정보를 보강한다. 필요한 안전 안내는 상황과 행동을 연결해 남긴다. 기존 검토 항목별로 변경 전후를 기록해 해결 여부를 판정한다.
4. **본원 정보와 의료 검토를 완료한다.** 실제 준비·퇴실 지침, 결과·발급 안내, 두 지역 지원사업 운영 여부를 확인한다. 확인되지 않은 수치·검토자·승인을 만들지 않는다.
5. **완료된 콘텐츠의 검색 공개 조건과 실적을 확인한다.** 실제 승인 범위를 확인한 뒤 기존 공개 검증 절차로 noindex·사이트맵 상태를 검토한다. 검색 공개 후 색인·유입·AI 인용을 관측하고, 신규 증상 글도 평가 질문에 포함한다. 페이지 수·키워드 수를 늘리는 것으로 대신하지 않는다.
