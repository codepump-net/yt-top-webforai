# 2026-09-26 홈페이지 콘텐츠 업데이트

원장님이 제공한 01~04 문서와 DOCX를 반영해 기존 74개 경로를 유지하고 심장·혈관 질환 20편을 추가했다. 현재 구현은 **94개 경로, 질문·답변 총 152개**다. 신규 원고의 질문 60개를 모두 포함한다.

사용자 지시에 따라 새 페이지는 영문 URL을 사용했다. 한글 URL은 원고 대응 기록에만 남겼으며 기존 URL 검증 규칙은 변경하지 않았다. 경로와 원본 대응은 [20편 적용표](article-mapping.ko.md), [구현 범위](implementation-coverage.json)에 있다.

## 적용 내용

- **심장·혈관 20편:** 정의·원인·증상·검사·치료·응급 신호·생활관리·병원 평가·의뢰·FAQ를 독립 페이지로 구성했다. 기존 PC·모바일 목차를 사용하고 질환백과·전체 페이지·검색·구조화 데이터에 연결했다.
- **기존 23개 페이지:** 검사·진료 설명과 관련 링크를 갱신하고, 비자 6개 언어의 방문 정보를 보완했다. 협심증·판막 해설의 기존 주소와 내용을 유지하고 새 질환 글에 연결했다.
- **검사 정보:** Troponin I는 원내 약 20분, CK-MB·Troponin T·CPK·D-dimer·NT-proBNP는 일반적으로 다음 날로 구분했다. IMA는 도입 예정으로만 표시한다. CART BP Pro의 24시간 착용과 반납 후 약 1시간 결과 확인을 검사·혈압 안내에 반영했다.
- **공통 안내:** 병원 정보·일반 안전·심장 예약·제출 서류 안내를 글 주제에 따라 출력한다. 중복된 취소 정책을 공통 안내로 옮겼고, 병원 정보는 접이식 패널로 제공한다. 원래 방문 정보가 있는 비자 글은 주소·시간을 다시 출력하지 않는다.
- **번역:** 기존 영어·중국어·태국어·러시아어·네팔어 비자 페이지에 해당 언어의 안전·서류 안내를 추가했다. 원문을 포함한 6개 언어의 방문 안내에 점심시간 검사 제한·조기 접수 마감·오후 5시 이후 전화 확인·지하주차 안내를 보완했다.
- **백과 분류:** 증상 7분류·질환 5분류의 이름과 순서를 적용했다. 현재 증상 목록 5개, 질환·관련 해설 목록 28개이며 신규 심장·혈관 질환 설명은 20개다. 진료 허브는 개별 백과 항목에서 제외했다. 관련 해설은 역할을 표시하고 실제 개수·구명칭 검색을 지원한다.
- **원고 편집:** 조사 오류·제작 과정 설명을 정리했다. 초기 정상 검사 결과의 한계를 보존하고, 급성 심근경색·대동맥박리의 모호한 외래 추적 결론을 응급 상황에 맞게 수정했다.
- **화면·접근성:** 공통 안내를 목차에 연결했고, 모바일 고정 연락 메뉴에 탐색 영역 이름을 부여했다. 분류 버튼의 표시·읽기 이름과 결과 수 문구를 수정했고, 검색에 첫 요약문을 포함했다. 인쇄 때 접힌 병원 안내도 표시되도록 보완했다.

## 근거와 게시 상태

20편은 제공된 DOCX, 병원 안내와 검사 운영 정보는 01·03번 문서에 근거한다. 개별 질환에는 NHS·미국심장협회·미국 국립심장폐혈액연구소의 해당 질환 자료를, 혈액검사에는 MedlinePlus 자료를 연결했다. 원고에 반복된 대분류 출처를 구체적인 참고자료로 바꿨다.

원본에는 박종설 원장·2026-09-25 검토 표기가 있고, 03에는 2026-09-26 통일 요청이 있다. 이 기록은 내부 대응표에 보존했다. 수정한 웹 편집본의 의료 검토 완료로 자동 전환하지 않았으며, 2026-09-26은 이번 편집일이다. 새 원고와 수정한 원고는 `pending`이고 `reviews.json`·기존 공개 승인 기록은 변경하지 않았다.

결과물은 **review 빌드(noindex, 빈 공개 XML sitemap)**다. 내부 계획용 sitemap에는 새 URL을 포함한다. 실제 의료·운영·공개 검증을 만족한 production 빌드에서 공개 sitemap에 포함된다. 수정된 내용에 기존 승인이 재사용되지 않는 검사도 유지했다.

## 검증

지정 Node.js 24.21.0에서 실행했다. Mac의 하네스는 `PYTHON=python3`로 실행했다. [검증 결과](verification.json), [공통 안내 적용 검사](article-guidance-audit.json).

- 콘텐츠: 94개 경로·5개 에셋 통과.
- 단위 검사 64개, 하네스 17개, lint·타입 검사 통과.
- 루트 주소: 94개 정적 검사·44개 브라우저 검사 통과.
- 배포 하위 경로 `/yt-top-webforai`: 94개 정적 검사·44개 브라우저 검사 통과.
- 대표 모바일 성능: 질환백과 99점·심부전 100점, 접근성·권장사항 각각 100점, CLS 0. 재검토에서 발견한 분류 버튼의 표시·접근성 이름 불일치도 수정 후 통과했다. SEO 66점은 검토 모드의 의도적인 noindex이며 검색 노출 성과가 아니다.
- 공통 안내: 하단 82개·안전문 81개·심장 예약 32개·서류 안내 14개. 대상별 누락·중복 0건.
- 질환 글 상단·펼친 하단 패널·질환백과 필터를 PC/모바일 화면으로 확인했다. 브라우저 검사에서 발견한 모바일 연락 메뉴의 탐색 영역 문제를 수정한 후 재검사했다.

## 확인 범위와 한계

흉통·어지럼·실신·다리부종 등 별도 원고가 없는 주제에는 새 페이지를 만들지 않았다. 증상 목록과 존재하는 진료·증상·검사·FAQ를 연결했으며, 모든 질환에 서로 다른 증상 페이지 3~5개가 연결되었다는 의미는 아니다.

웹 편집본의 최종 의료·운영 확인과 다섯 언어의 번역 확인은 별도다. 자료에 없는 BNP 자체의 시행 여부, 혈액검사의 원내·위탁 구분, 가격·장비 준비 세칙을 임의로 추가하지 않았다.

실제 배포는 수행하지 않았다. 기존 공지·진단 사례 원문 링크와 운영 사이트 상태를 보존했다. 내부 원고·계획·검증 자료는 `web/out/`에 포함하지 않는다.

재검토에서 발견한 수정 사항과 세션 요약은 [작업 요약](session-summary.ko.md)에 정리했다.
