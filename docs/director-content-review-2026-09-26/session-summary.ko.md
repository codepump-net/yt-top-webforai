# 2026-09-26 홈페이지 반영·재검토 작업 요약

원장님이 제공한 `plan/01~04`와 DOCX를 기존 사이트에 반영하고, 원고 대응·문구·분류·검색·공통 안내·화면을 다시 검토했다. 기존 74개 경로를 유지하면서 심장·혈관 질환 20편을 추가해 **총 94개 경로, FAQ 152개**로 구성했다. 한글 주소는 원고 대조에만 사용하고 실제 페이지는 기존 영문 URL 규칙을 따른다.

## 요구사항 반영

| 자료 | 적용 내용 |
|---|---|
| 01 공통 안내 | 병원 위치·시간·주차, 의료 안전, 심장검사 예약, 제출 서류 안내를 대상 글에 한 번씩 출력 |
| 02 백과 분류 | 증상 7분류·질환 5분류의 이름·순서 적용, 이전 명칭 검색과 실제 글 수 표시 |
| 03 통합 반영안 | 혈액검사 6종·결과 시간, IMA 도입 예정, CART BP Pro의 착용·결과 시간 반영. 기존 진료 허브와 협심증·판막 해설 유지 |
| 04 게시목록·DOCX | 질환 20편과 원고 FAQ 60개 수록. 백과·검색·HTML 전체 페이지 및 관련 검사·진료·해설 연결 |

## 재검토에서 보완한 사항

- 20편의 주요 설명·목록을 원문과 대조하고 FAQ 60개의 질문·답변이 빠짐없이 유지됨을 확인했다. 원고의 `역류이란`, `박리이란` 등 조사 오류 교정을 재확인하고 심근염 설명의 `평가는 … 필요합니다`를 `평가에는 … 필요합니다`로 다듬었다.
- 분류 버튼의 보이는 글 수와 읽기 보조 기능의 이름을 일치시켰다. 선택한 분류를 결과 수에 표시하고, 글이 없는 분류에는 검색 실패와 구분되는 안내를 제공한다.
- 본문 첫 요약문도 검색 대상에 포함해 정의에 나오는 표현으로 해당 질환을 찾을 수 있게 했다.
- 비자 안내 6개 언어의 기존 방문 설명에 점심시간 검사 제한·조기 접수 마감·평일 오후 5시 이후 전화 확인·지하주차 안내를 보완했다.
- 인쇄할 때 접힌 병원 안내도 펼쳐지며, 인쇄 후 원래 상태로 돌아오도록 수정했다. 자바스크립트가 꺼진 인쇄 화면도 확인했다.
- 기존 페이지는 총 23개에서 본문 또는 관련 링크를 갱신했다. 공지·진단 사례의 기존 홈페이지 원문 연결은 유지했다.

## 검증 및 게시 상태

Node.js 24.21.0에서 콘텐츠 94개 경로·에셋 5개, 단위 검사 64개, 하네스 17개, lint·타입 검사를 통과했다. 루트와 `/yt-top-webforai` 하위 경로에서 각각 정적 검사 94개·브라우저 검사 44개를 통과했다. PC·모바일 화면도 직접 확인했다. 상세 결과는 [검증 기록](verification.json)에 있다.

9월 26일 로컬 검토 후 사용자 요청에 따라 **9월 27일 기존 Pages에 배포했다.** 실제 94개 경로의 검증을 통과했으며 [배포 기록](deployment.ko.md)에 결과를 남겼다. 의료 검토 완료나 공개 승인을 새로 생성하지 않았고 `noindex`와 공개 전 검증을 유지한다. 공개 XML 사이트맵은 검토 모드에서 비어 있으며, 신규 경로는 내부 계획용 사이트맵에 포함된다.

별도 원고가 없는 증상 글은 임의로 만들지 않았다. 따라서 모든 질환에 서로 다른 증상 페이지 3~5개가 연결된 상태는 아니다. 웹 편집본의 최종 의료·운영 확인과 외국어 번역 확인이 남아 있다. 원본 검토일 9월 25일과 요청 문서의 9월 26일은 내부 기록에 구분했으며, 웹 편집일을 의료 검토일로 표시하지 않았다.
