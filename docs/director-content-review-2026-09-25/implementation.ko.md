# 2026-09-25 콘텐츠 개편 구현 결과

원장님 원고 `plan/new_20260925.md`의 46편을 현재 환자용 사이트에 반영한 개발 결과다. 원고별 대응은 [구현 대응 기록](implementation-coverage.json), 최초 검토는 [종합 검토](README.ko.md)를 참고한다. 이 문서는 공개 사이트에 포함되지 않는다.

후속 요청: 사용자가 구현 완료 후 배포하고 원장님에게 검토를 요청하겠다고 지시했다. 기존 Pages 주소에 review 모드로 배포하는 과정과 결과는 [배포 기록](deployment.ko.md)에 별도로 남긴다. 아래의 미배포·승인 대기 설명은 구현 완료 당시의 상태다.

## 반영 범위

- 기존 45개 경로를 유지하고 한국어 핵심·심화 안내 21개, 비자검진 외국어 안내 5개를 추가했다. 총 71개 경로이며 색인 대상 후보는 69개다. 검색과 404는 계속 비색인이다.
- 원고 46편 모두 반영 위치를 기록했다. 46개 글을 그대로 복제하지 않고 주제별 기존 페이지 보강, 독립 안내, 관련 링크로 통합했다.
- 주소 6층 609호, 토요일 점심시간 없음, 평일 점심에는 접수만 가능, 지하주차, 심장초음파·홀터 예약, 평일 17시 이후 전화 확인을 공통 정보에 반영했다.
- 박종설 원장의 보라매병원 경력, 서울메디칼초음파아카데미 전직 표기, 내시경·초음파 자격을 수정했다. 박라영 원장의 소개와 실제 사진이 아닌 이미지 표시는 유지했다.
- 심전도·주로 72시간 홀터·심장초음파의 선택 과정, Troponin I 원내 약 20분, 원내·위탁검사의 결과 확인 표, CT·갑상선 세침흡인검사·입원 치료의 의뢰 범위를 추가했다.
- 암환자 지지진료, 항암 중 38℃ 발열, 치료 종류와 9가지 증상별 대처, 호중구 증가 주사제의 조건, 후버바늘 제거와 포트 기기 제거의 차이를 설명했다.
- 오라팡·플렌뷰 준비, 동행 귀가, 복약 상담, 조직검사와 용종절제 후 회복을 연결했다. 급성 복통, 호흡기 감염, 독감·코로나, 만성질환·간질환, 성인 예방접종과 심화 건강정보를 추가했다.
- 국가암검진 5종과 폐암검진 미시행, 채용·공무원·비자·결핵 서류의 준비와 조건을 구분했다. 기존 공지 채널과 25개 진단 사례 원문 링크는 유지했다.

## AEO·GEO와 환자 이용 기능

질문에 대한 직접 답변, 표, 목록·순서, 증상별 긴급 행동과 관련 진료·준비·후속 관리 링크를 정적 HTML로 제공한다. 추가된 목록과 단계도 사이트 검색에서 찾을 수 있다. 검색 제목·소제목과 전용 상세 안내의 관련성을 반영해 종합 페이지보다 세부 안내가 적절하게 노출되도록 보강했다.

FAQ의 답변과 JSON-LD는 동일한 데이터에서 만든다. 기존 병원 ID `https://yttop.co.kr/#clinic`을 유지하고 신규 사이트·페이지는 자기 URL을 사용한다. 임의의 의료 검토자, 평점, 치료 성과나 AI 인용 성과를 추가하지 않았다.

비자검진은 한국어·영어·간체중국어·태국어·러시아어·네팔어의 같은 6개 절로 제공한다. 각 페이지의 `html lang`, 언어별 metadata, `inLanguage`, 자기 canonical, 6개 언어와 x-default의 상호 `hreflang`을 검증한다. 번역 페이지는 진료·통역 가능 언어를 뜻하지 않으며 ContactPoint의 확인된 한국어 안내는 유지했다. Next.js의 언어별 루트 레이아웃과 공통 404를 사용한다.

평가 질문은 53개로 확대했고, 병원명을 먼저 주입하지 않는 13개 대화 시나리오(39개 턴)를 추가했다. 최초 응답·후속 응답의 인용률, 기존/신규 사이트의 인용, 앞선 인용의 유지, 병원명을 질문에 넣지 않은 응답의 언급, 오류·미완료 대화를 구분한다. **실제 AI 응답 수집이나 노출 향상 측정은 이번 구현에서 수행하지 않았다.**

## 운영 공개 전 확인할 실제 항목

원고의 2026-09-24 작성·검토 표기는 제공된 원고의 정보다. 통합·수정·번역한 이번 전체 사이트의 최종 의료 검토 완료 기록으로 자동 전용하지 않았다. 기존 9월 11일 공개 승인 파일도 변경하지 않았다.

1. 오라팡 실제 병원 배포 안내문의 물 양·속도·예약별 시간과 제품 설명서의 관계.
2. 평일·토요일 검사별 접수 마감, 서류 예상 발급일, 심장검사 취소·재예약 정책의 현재 운영 적용.
3. 실제 국내 제품·예방접종 일정·암 지지진료 조건을 포함한 편집본 의료 확인.
4. 비자 제출처 지정기관 요건과 5개 번역판의 운영·언어 확인. 현재 사이트는 기관 인정이나 통역을 보장하지 않는다.

`docs/patient-content-policy.ko.md`의 “실제 승인 자료가 없는 동안에는 기존 review 빌드의 noindex와 production 검증을 유지한다”는 기준에 따라, 새 편집본은 검토용 출력으로 만들었다. 이전 승인 digest가 새 콘텐츠와 맞지 않아 production 검증이 거절하는지 확인한다. 사용자 요청은 개편 구현으로 처리했으며 새 의료 승인·공개 승인 사실을 생성하지 않았다. 현재 운영 사이트의 기존 콘텐츠나 배포를 변경하지 않았다.

실제 게시 단계에서는 확인된 새 승인 범위를 기록하고 release 빌드·배포·같은 빌드 매니페스트 기반 live 검증을 진행해야 한다. 프로젝트 경로의 robots.txt가 호스트 루트 robots.txt를 대신하지 않는 점과 Search Console 접근·설정은 운영 환경에서 확인한다. 루트 robots.txt 부재를 접근 차단이라고 표현하지 않는다.

## 재현 방법과 관측 기록

Node.js 24에서 `web/` 디렉터리를 기준으로 실행한다.

```sh
npm ci
npm run content:validate
npm run lint
npm test
PYTHON=python3 npm run harness-check
SITE_ORIGIN=https://codepump-net.github.io SITE_BASE_PATH=/yt-top-webforai npm run build
npm run typecheck
npx playwright install chromium
npm run test:e2e
npm run test:performance
npm run serve
```

검토용 URL: `http://127.0.0.1:3000/yt-top-webforai/`. 검토 출력의 noindex와 비어 있는 공개 sitemap은 의도된 동작이다. 검토 대상 69개 URL 목록은 공개 폴더 밖의 `web/reports/planned-sitemap.xml`에 있다.

측정은 실제 관측 파일이 생긴 뒤 `npm run measure -- <관측파일>` 또는 `npm run measure:conversations -- <대화관측파일>`로 실행한다. 대화 관측에는 scenarioId, conversationId, turn, 정확한 prompt, historyMode=`same-thread`, engine, period, language, runId 대신 conversationId, querySetVersion, status와 실제 answer/citations를 기록한다. model·region·searchMode도 일정하게 기록한다. 정확성 판정은 실제 reviewer와 boolean label이 있는 답변만 집계한다. 원문 대화에는 민감한 환자정보를 넣지 않고 비공개 위치에서 보관한다.

최종 자동 검사 수치와 출력 digest는 [검증 기록](implementation-validation.json)에 기록한다. 의료적·번역상 정확성을 자동 검사 통과와 동일시하지 않는다.
