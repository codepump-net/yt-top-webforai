현재 구간은 `aria-current`와 밑줄로 표시합니다. 공지 목록의 5개 카드에 게시일을 넣고 과거 휴진에는 별도 배지를 붙였습니다. 의료 원고·운영 원장의 사실과 응급 맥락 페이지의 별도 문의 CTA 제외 정책은 유지했습니다.
