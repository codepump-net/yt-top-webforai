# 2026-11-16 문서 구조화·검증 기록

이 기록은 이번 프로젝트 분석·문서 작업의 실행 결과다. 새로운 의료 검토·검색 성과·운영 배포 완료를 의미하지 않는다.

## 1. 변경 범위

- 현행 목표·사용자·사이트맵·시스템·모델·디자인·SEO·개발·운영·백로그 문서.
- 기능 명세 16개와 기계 판독 카탈로그, 모든 135개 경로의 주 담당 기능 연결.
- `pwd-2026-2 lecture 09`용 수업 운영안·워크숍·제출물·평가 제안.
- 기능 명세·작업·ADR 템플릿과 문서 구조 결정 기록.
- 원장으로 인벤토리·전체 경로 CSV를 생성·검사하는 docs 전용 도구.
- 저장소·docs·앱·콘텐츠 README와 이전 인수 문서의 현행 진입점 안내.

기존 날짜별 보고서의 경로·증거는 보존했다. 환자용 원고·앱 코드·자산·출판 확인·워크플로는 변경하지 않았다. 기존 루트의 미추적 Google·Naver 확인 HTML은 그대로 두었다.

## 2. 실행 환경

분석 기준 코드 `50412dc`, macOS arm64, Node.js **24.21.0**. 전역 Node는 26.x여서 저장소의 기존 `.local/runtime/node-v24.21.0-darwin-arm64/bin/`을 사용했다. 새 런타임 설치나 패키지 갱신은 하지 않았다. Python 하네스는 `PYTHON=python3`로 실행했다.

## 4. 수치와 남은 경계

인벤토리는 현재 원장에 설정된 135개 경로·132개 색인 후보, 한국어 130개·번역 5개, 의료진 2명, 등록 자산 38개, 안내 공지 6편, 원 사례 링크 25개, 질문 73개·대화 13개·39턴을 기록한다. 실제 검색 노출·환자 방문·AI 인용 결과가 아니다.

docs 도구의 검사 기능은 수동 실행 가능하며 현재 Pages CI에는 편입하지 않았다. 새로운 내용·기능을 개발할 때는 해당 명세·실제 확인·검증·생성 문서를 함께 갱신한다. 강의 원본은 확인하지 못했으므로 수업 자료는 보조안으로 표시했다.

## 5. 후속 요청: 날짜별 의뢰자 자료 폴더 분리

사용자가 날짜가 적힌 기존 폴더들을 의뢰자의 요청서로 설명하고 별도 폴더에 모아 관리해 달라고 요청했다. 이에 기존 날짜 포함 폴더 26개·680개 파일을 `docs/client-requests/`로 이동하고 [전체 요청 색인](../client-requests/README.md)을 만들었다. 위 1~4절은 이동 전 최초 문서 정리의 기록이며, 보관 위치 결정은 [ADR 0002](../decisions/0002-client-request-collection.ko.md)로 갱신했다.

| 후속 검사 | 결과 |
|---|---|
| 이동 누락·루트 정리 | 26개 폴더·680개 파일 확인, docs 바로 아래 날짜 폴더 0 |
| 원시 증거 보존 | Markdown·HTML·스크립트를 제외한 590개 파일의 이동 전후 해시 일치 |

과거 JSON·로그 등에 남은 이전 경로는 당시 실행 이력으로 보존했다. 이를 읽는 로고 자료 처리 도구는 현재 위치로 해석하도록 수정했다. 환자용 원고·앱 화면·공개 확인·배포 설정은 폴더 정리 때문에 변경하지 않았고 운영 배포는 수행하지 않았다.
