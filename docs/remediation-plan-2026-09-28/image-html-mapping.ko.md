제공 안내도 5개와 HTML 보완 명세

대상 이미지는 한 장의 모음판에서 분리한 원본을 그대로 유지한다. 개별 고해상도 원본을 다시 요구하거나 글자를 지운 새 삽화를 제작하는 작업은 포함하지 않는다. 작은 글자 가독성은 모바일에서도 읽을 수 있는 HTML 표·단계 설명으로 보완한다.

| 안내도·페이지 | 현재 차이 | 만들어야 할 HTML | 실제 대조할 항목 | 확인 연결 |
|---|---|---|---|---|
| 성인 예방접종 · `/services/vaccinations/` | 기존 9개 백신 표는 이전 제공 자료에서 구성됨. 현재 모음판의 작은 각주·추가 문구까지 같은지는 판정되지 않음 | 백신·대상·기본 일정·추가 조건의 표와 적용 기준 설명 | 9개 백신 각 행의 이름·일정·대상·주의조건, 원본의 하단 추가 문구, 기존 표와 원자료의 차이. 핵심 정보가 없는 장식 문구는 전사 대상에서 구분 | E10, E11; 공식 예방접종 근거. 사업별 본원 운영은 C09·C10 |
| 심장검사 · `/services/heart/` | 이미지 6단계와 기존 HTML 4단계가 다름. 본문은 모든 검사를 연속해서 받는 것처럼 읽힐 수 있음 | 접수·증상 평가·심전도·증상별 추가검사·결과 계획의 관계를 보여주는 목록과 검사별 목적 표 | 이미지의 6개 항목과 세부 검사명·결과 안내를 대응시킴. 공통 진료 과정과 선택 검사를 구분하며 선택 조건은 명시 | E02, E11, C04·C12 |
| 내시경 준비 · `/services/endoscopy/` | 원본 6단계의 준비 정보와 HTML 4단계의 ‘안내 확인’ 중심 설명 차이 | 검사 전 음식·금식·장정결·복용약·동행·당일 준비의 표 | 각 단계가 위/대장, 진정/비진정, 정결제별 어느 경우에 적용되는지. 원본의 모든 핵심 조건을 연결 | E03, E11, C01 |
| 조직검사·용종절제 후 · `/health/after-endoscopy/` | 원본의 구체 시간·활동 제한과 HTML의 ‘시각 확인’ 중심 설명 차이 | 시술 종류와 경과 시간·식사·활동·복약·위험 신호를 구분한 표 | 원본 ‘약 2~3시간 후’, ‘약 6~8시간 후’ 등 표기의 시작 기준·적용 대상. 원본의 후속 기간·경고까지 대조 | E03, E11, C02 |
| 검진 절차 · `/checkups/` | 원본 5단계 및 아래 검진 종류 안내와 HTML 4단계의 제출 서류 중심 설명 차이 | 국가검진과 제출용 검진의 진행 흐름, 종류별 준비·결과/서류 수령 표 | 국가·채용·공무원·비자 등 실제 원본의 구분과 기존 허브 연결. 제출용 양식·봉인 조건을 일반 국가검진에 적용하지 않음 | E01, E08, E11, C04·C05 |

작업자는 각 원본의 핵심 문구에 식별자를 붙이고 `원본 위치 / 판독한 문구 / 적용 대상 / 현재 HTML 위치 / 보완 후 위치 / 근거 / 확인 상태`를 기록한다. 읽히지 않는 작은 글씨는 내부 원장에 판독 불가로 남기고 이전 제공 자료·본원 지침·공식 자료로 대조한다. 추정한 문구를 원본 전사로 표시하지 않는다.

관련 설명 제목을 바꾸거나 ‘개별 안내를 따르세요’라는 문단을 하나 더 붙이는 것으로 정보 대응을 완료 처리하지 않는다. 제공본과 본원 현행 기준이 충돌한다면 두 값을 동시에 정답처럼 싣지 않고 해당 내용의 처리 상태를 미완료로 기록한다. 원본 변경이 필요한 경우에는 기존의 원본 보존 지시와 구분해 정정 방향을 받아야 한다.

완료 확인은 다음 여섯 가지다.

1. 원본 17개의 파일·픽셀·배치 보존 검사를 통과한다. 이 작업에서 그림의 글자·로고·내용을 바꾸지 않는다.
2. 5개 안내도의 핵심 단계·일정·주의사항이 HTML의 특정 위치와 연결된다. 단순한 단계 개수 일치는 동등한 정보의 증거로 사용하지 않는다.
3. 이미지·HTML·페이지 요약 사이에 적용 대상과 수치의 미해결 충돌이 없다. 충돌이 남은 항목은 완료 수에 넣지 않는다.
4. 390px 화면에서 HTML 설명을 확대 없이 읽고 필요한 표를 이용할 수 있으며, 1440px에서도 흐름이 명확하다. 가로 넘침과 조작 방해를 확인한다.
5. 안내도 확대·키보드 복귀·자바스크립트 없는 원본 접근을 유지한다. 대표 배너 12개의 확대 기능과 불필요한 삽화 설명은 다시 추가하지 않는다.
6. 출처·수정일·실제 의료 검토 범위를 구분해 기록한다. 이미지 픽셀 검사와 의학적 정보 대조의 결과를 따로 남긴다.
