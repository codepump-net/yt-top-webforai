# 영통탑내과 AEO·GEO 개선 반영과 전후 비교

작업일: 2026-09-11. **실제 원고·렌더러·검증·관측 도구에 반영한 결과**다. 내부 개발·평가 문서이며 병원 홈페이지에 게시하지 않는다. 기존 사이트와 병행 운영하는 현재 45개 경로를 유지했다.

## 1. 결론

**기존의 짧고 반복적인 안내를 구체적인 환자 질문·비교표·준비 안내·설명별 출처 연결로 개선했다. AEO의 답변 구체성과 GEO의 근거 추적 구조는 변경 전보다 분명히 보강됐다.** 의료 상세 25개 전체를 포함해 원고 데이터 36개 페이지를 수정하고, 나머지 9개는 기존 역할을 유지했다. 공통 메타·병원 정보 변경은 원고가 그대로인 페이지에도 적용된다.

기존 레퍼런스의 상세 설명·비교·출처 연결에 가까워졌고, 일관된 병원 ID·공통 사실 변경 전파·내부 자료 분리에는 검증 가능한 강점이 있다. 그러나 **실제 의료진의 검토·정확한 병원별 준비 지침·검색 공개·AI 인용 성과까지 레퍼런스를 넘어섰다고 판정할 단계는 아니다.** 저자 이름을 임의로 붙이거나 미확정 숫자를 채워 이 간격을 숨기지 않았다.

상세 25페이지에서 도입과 본문 블록 텍스트 길이는 209~316자에서 **427~646자**가 됐다. 표·질문·출처·공통 UI는 이 수치에서 제외했다. 더 긴 원고를 요구하는 검색 기준을 충족했다는 뜻이 아니며, 질문을 충분히 해결하는지는 별도의 편집·의료 검토 대상이다.

## 4. GEO를 위한 실제 구현

본문 절과 질문에 안정적인 ID, `sourceIds`, 문맥 링크, 필요한 표를 추가했다. 출처는 해당 페이지의 제목·URL·유형과 연결된다. 의료 출처로 외부 개인 Q&A 플랫폼을 자동 채택하지 못하도록 검사하고, 없는 출처·페이지·절 참조는 빌드 전에 거절한다. 이 구조는 **절·질문 단위의 근거 연결**이며 모든 문장의 임상적 적합성을 자동 인증하는 시스템은 아니다.

심장초음파는 기존 대학병원 자료를, 검사 비교·리듬은 NHLBI 안내를, 내시경은 NIDDK와 기존 대학병원 자료를 연결했다. 기침·갑상선·복부·경동맥·ABI·HRV·심장 표지자 등에 해당하는 공식 의료기관·공공기관 설명도 추가했다. 원문을 환자 안내로 번역·복제하는 대신 기본 사실을 대조하고 자체 설명·방문 준비를 작성했다.

현재 연결한 외부 의학 출처 18개는 이번 HTTP 확인에서 모두 최종 200 응답을 확인했다. 트로포닌 링크는 첫 요청 실패 뒤 재시도에 성공했다. HTTP 성공은 내용 정확성이나 이용 허가의 인증이 아니다. [출처와 사이트 응답 기록](source-probes.json).

병원 기본정보는 `content-model.mjs`를 통해 원고와 메타·JSON-LD가 같은 값을 사용하도록 했다. `clinic.addressParts`에서 주소를 생성하고, 전화·주소·시간을 본문에 써야 할 때는 허용된 공통 참조를 해석한다. 알려지지 않은 참조나 잘못된 시간 구간은 거절한다. 입력을 바꾸었을 때 기존 전화·주소가 남지 않는 단위 검사를 추가했다.

기존 병원의 시간·위치·심장초음파 안내와 지도 연결을 재확인했다. 평일은 점심 전후 구간으로 구조화했고, 토요일은 점심 적용이 불명확해 schema의 요일 구간에서 제외했다. 공개 화면에는 기존 토요일 시간과 문의 안내가 남는다. **시간 schema의 존재를 전체 요일·공휴일 운영 검증 완료로 해석하지 않는다.** 위치 좌표와 주차 지원 수치를 추정하지 않았다.

실제 의료 검토 기록에는 `reviewerId`와 프로필의 이름이 맞는지 검사하고, 승인 후 해당 프로필로 연결할 수 있게 했다. 현재 기록은 0개여서 화면과 JSON-LD의 검토자 표시도 0개다. 외부 Q&A 답변자나 기존 의료진을 자동 작성자로 지정하지 않았다.

## 5. 레퍼런스와 다시 비교한 판정

레퍼런스는 이전에 수집한 공통 HTML 각 7개·의료 글 각 3개와 그 감사 기록을 비교 기준으로 재사용했다. 이번에는 각 정식 블로그 홈의 200 응답을 다시 확인했으며 의료 글 전체를 새로 수집·임상 검수하지 않았다. 질환·페이지 역할이 달라 같은 의학 질문의 답변 우위를 실험한 비교도 아니다.

| 축 | 개선 후 영통탑 | 레퍼런스 대비 판정 |
|---|---|---|
| 정적 HTML·고유 메타·탐색 | 전체 45경로 검증, 기존 강점 유지 | 유사한 기술 기반을 갖춤; 기존 원 병원보다는 정보 접근 구조가 개선됨 |
| 답변 구체성·준비·비교 | 상세 25개 확장, 13개 실제 조사 주제 반영, 표 6개 | 이전의 얕은 FAQ 구조에서 개선; 레퍼런스의 긴 질환별 설명까지 전면 우위라고 하기는 어려움 |
| 근거 연결 | 참고 목록 외에 절·질문 가까이 출처 제공 | 근거를 따라가는 구조 보강; 실제 주장 적합성의 의료 검토는 미완료 |
| 병원 정보 일관성 | 병원 ID 하나, 주소·전화·시간 참조와 변경 전파 검사 | 이전 표본의 병원 ID 분산·정보 충돌을 피하는 검증 가능한 강점 |
| 로컬 상세 정보 | 평일 시간·지도 schema 추가 | 일부 격차 축소; 레퍼런스의 좌표와 상세 운영 정보까지 동일하게 충족하지는 못함 |
| 작성·검토 책임 | 실제 승인 전 표시하지 않음 | 저자 연결이 있는 상대 표본과의 표시 격차가 남음; 상대의 실제 비공개 검토 수행 여부는 확인 불가 |
| 실제 공개·검색·AI 성과 | review noindex, 예정 URL 404 | 정식 운영 중인 두 블로그와 같은 공개 조건이 아님; 우위 판정 불가 |

별도의 작성·검수 정책 페이지, 지역명만 바꾼 페이지, 복제 사례·공지 상세를 다시 만들지 않았다. 홈페이지의 기본 역할과 병행 운영 경계는 유지했다.

## 6. 기술 검증과 성능 전후

- 루트 경로와 GitHub Pages 프로젝트 경로 각각 **45경로 정적 감사, 브라우저 테스트 29개 통과**. 각 실행에 전체 페이지 HTML·JS 없는 접근, 13개 조사 질문, 표·출처·문맥 링크·모바일·키보드·인쇄·폐기 경로 검증이 포함된다.
