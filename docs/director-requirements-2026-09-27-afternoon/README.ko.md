> 2026-09-28 개발 결과는 [구현 결과](implementation-results.ko.md)를 참고하세요. 아래는 작업 전 분석 기록입니다.

분석일: 2026-09-27. 내부 검토 문서이며 환자용 사이트에 게시하지 않는다.

후속 평가: [작업 전후 상태·개선 작업 26개·완료 기준](work-items.ko.md), [이미지 17종·공지 6주제·증상 20주제의 개별 명세](scope-register.ko.md).

## 1. 분석 범위와 결론

현재 `plan/`의 문서·이미지를 읽고, 현재 작업 폴더의 사이트 콘텐츠·화면 구성과 대조했다. 배포·통합·자동 적용 절차와 특정 기술·컴포넌트 사용 지시는 이 요구사항 정리에서 제외했다. 원본 자료를 삭제하거나 고치지 않았고, 사이트 콘텐츠·코드도 변경하지 않았다.

핵심 요청은 다음 네 가지다.

1. **진료분야와 안내 페이지를 그림으로 쉽게 구분하고, 준비·진행·관리 과정을 시각적으로 설명한다.** 대표 배너 12종과 실용 안내도 5종이 제시되어 있다.
2. **예방접종 지원사업과 감염병 소식을 환자가 쉽게 찾도록 한다.** 공지 주제 6개, 홈의 최근 공지, 공지의 기간·상태·출처 표시를 요구한다.
3. **질환명을 모르는 환자도 증상에서 출발해 심장·혈관 안내를 찾도록 한다.** 질문형 주제 20개와 관련 검사·질환·후속 안내의 연결을 요구한다.
4. **콘텐츠 이용과 출처·권리 범위를 설명한다.** 저작권 상세 안내, 의료정보 글 하단의 짧은 문구, 사이트 공통 하단 링크를 요구한다.

이는 자료의 명시적 요청을 환자 관점으로 정리한 것이다. 새로운 전체 디자인, 진료체계 개편, 의료진 소개 변경, 예약 기능 신설은 이번 자료에서 확인되지 않는다. 배너의 통일된 그림 스타일은 확인되지만, 사이트 전체를 그 스타일로 재설계하라는 요구로 확대하지 않는다.

‘현재 사이트’는 **이 저장소의 현재 콘텐츠와 화면 코드**를 뜻한다. 실제 운영 사이트의 현재 화면이나 외부 사업의 최신 조건을 새로 확인한 보고서는 아니다. 의학적 내용·지원 자격·저작권 문구의 타당성 확정도 이번 분석에 포함하지 않는다.

따라서 현재 자료로 요구사항과 주제는 정리할 수 있지만, 완성 원고나 개별 이미지의 세부 내용을 전부 확인했다고 볼 수 없다.

위 명칭은 **전달 자료의 주제명**이며, 해당 사업의 실제 시행 여부·대상·기간을 이번 분석에서 인증한 것이 아니다.

내용과 화면에 대한 명시적 요구:

- 공지에서 게시일·최종 확인일·사업 기간·상태·공식 출처를 확인할 수 있게 한다.
- 종료된 정보는 ‘기간 종료’로 구별해 과거 정보를 현재 지원으로 오해하지 않게 한다.
- 홈의 진료시간·오시는 길 위에 최근 공지를 보여준다.
- 병원안내에서 공지에 접근할 수 있게 한다.
- 감염병 안내의 원문 PDF를 열고 내려받을 수 있게 한다.
- 지정·참여기관 여부를 확인하기 전에는 본원에서 지원접종이 가능하다고 단정하지 않는다.

**콘텐츠 운영 원칙과 조정할 점:** 전달 자료는 신규 사이트의 공지 상세 6개를 제안한다. 현재 [환자 콘텐츠 기준](../patient-content-policy.ko.md)은 기존 홈페이지를 공지 원 게시 채널로 유지하고, 신규 사이트의 `/notices/`는 그 게시판으로 연결하도록 정한다. 이는 단순한 기술 적용 문제가 아니라 환자가 어느 채널에서 최신 공지를 확인하는지에 관한 문제다. 지금 확정할 요구는 ‘최신 소식의 접근성과 내용 보강’이며, 상세글을 어느 채널에 둘지는 미결 사항으로 남긴다. 이번 자료만으로 기존 공지 원문을 복제하거나 게시 채널 변경을 확정하지 않는다.

## 6. 심장·혈관 증상백과에서 도출한 요구사항

기존 질환백과는 진단명에서 출발한다. 새 목록은 가슴 답답함·두근거림·어지럼·호흡곤란·부종처럼 환자가 겪는 상황에서 출발한다. 자료는 독립 글 20편을 요구하지만 본문은 제공하지 않아, 기존 글과 어느 정도 겹치는지는 제목 수준에서만 판단할 수 있다.

이 표의 관련 안내는 원고 대조 후보이며, 해당 증상이 곧 특정 질환임을 뜻하지 않는다.

공통 요구는 심장·혈관 분류에서 20개 주제를 찾을 수 있게 하고, 검색어의 다른 표현을 지원하며, 관련 검사·질환·후속 글로 연결하는 것이다. 각 글에는 위험 신호, 검사와 의뢰 판단에 필요한 설명, 근거와 실제 작성·검토 정보를 갖추도록 요청한다. 원고 전달 사실이나 파일 날짜를 의료 검토 완료로 표시하는 요구로 해석하지 않는다.

특히 기존 `/health/palpitations-test-followup/`와 신규 5번 글의 상호 연결은 자료에 명시되어 있다. 실제 원고를 확보하면 ‘처음 증상이 있을 때’와 ‘검사 후에도 계속될 때’처럼 독자 상황을 나눌 수 있는지 확인한다. 이 구분은 현재 단계의 편집 제안이다.

## 7. 저작권 안내에서 도출한 요구사항

- 상세 안내에서 링크 공유·인용·복제 등 콘텐츠 이용 범위를 설명한다.
- 의료정보 글 하단에는 짧은 안내를 한 번만 표시한다.
- 사이트 공통 하단에 상세 안내 링크와 저작권 문구를 둔다.
- 병원 자체 작성·제작 자료와 외부기관 자료의 출처·권리 범위를 구분한다.

자료의 취지는 ‘정당한 인용과 링크 공유를 허용하고 무단 복제·전재·재게시·변형·상업적 이용을 제한하는 안내’다. 이는 요청 의도의 요약이며 구체 문구의 법적 효력을 확인한 결론은 아니다. 실제 상세 원고는 현재 폴더에 없다.

## 8. 이번 단계에서 정리된 작업과 남은 확인사항

| 구분 | 정리된 내용 |
|---|---|
| 새 콘텐츠 요청 | 증상 중심 주제 20개, 공지 주제 6개, 콘텐츠 이용 안내 |
| 기존 화면 보완 요청 | 대표 배너, 검사·관리 안내도, 홈 최근 공지, 글·사이트 하단의 이용 안내 |
| 이미 있는 기능·내용 | 공지 진입 페이지·병원안내 연결·푸터 링크, 예방접종 그림·표·확대, 질환백과 20편, 검사·관리의 설명 글 |
| 자료에서 바로 확인한 오류 | 7번 신장 배너의 ‘심장질환’ 제목 |
| 원고를 보고 결정할 내용 | 증상 글 사이와 기존 글 사이의 중복, 정확한 배너·안내도 배치, 기존 예방접종 일정표와 새 자료의 판본 차이 |
| 사실 확인이 필요한 내용 | 공지의 공식 조건·기간·출처, 특히 수원시·경기도 사업의 본원 참여 여부, 이미지와 본문의 의료 설명 일치 |
| 콘텐츠 운영상 미결 사항 | 기존 공지 원 게시 채널을 유지하면서 새 공지 주제를 어떻게 안내할지 |
| 자료 확보가 필요한 항목 | 개별 이미지, 상세 원고, 이미지 설명·배치 자료, 감염병 PDF |

환자 사례를 새로 공개하라는 요청은 없다. 자료도 기존 사례를 검색·관련 글에서 다시 노출하지 않는 원칙을 유지하도록 명시한다.

이 문서는 요구사항 분석 결과다. 사이트 수정, 이미지 제작·수정, 원고 작성, 기술 적용이나 배포 작업은 시작하지 않았다. 공개 페이지 변경이 없어 사이트 빌드·콘텐츠 검사는 실행하지 않았으며, 대신 자료 목록·주제 수·현재 경로와의 대조 및 이미지 육안 확인을 수행했다.
