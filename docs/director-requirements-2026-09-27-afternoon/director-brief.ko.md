**영통탑내과 홈페이지 개선 작업 보고**

2026년 9월 28일 작업 기준

원장님께서 보내주신 자료를 현재 홈페이지와 비교해, 환자가 진료 정보를 쉽게 찾고 검사·방문을 준비하는 데 필요한 내용을 개발 중인 홈페이지에 반영했습니다.

| 최초 요청 | 진행 방법과 반영 결과 |
|---|---|
| 진료분야별 대표 그림 12종 | 보내주신 그림 모음판을 참고해 AI로 설명용 삽화 12종을 새로 제작하고 해당 페이지에 배치했습니다. 신장 분야에 잘못 붙어 있던 ‘심장질환’ 제목은 ‘신장질환’으로 바로잡아 표시했습니다. |
| 검사·관리 안내도 5종 | 기존 예방접종 일정표를 유지하고, 심장검사·내시경 준비·조직검사 및 용종절제 후 관리·검진 진행 안내도 4종을 추가했습니다. 그림의 내용은 글로도 읽을 수 있고 휴대전화에서 확대할 수 있습니다. |
| 예방접종·감염병 공지 6주제와 홈 화면 안내 | HPV, 폐렴구균, 국가 독감접종, 수원시 대상포진, 경기도 학생 독감접종, 감염병 예방 안내를 공식 자료와 대조해 정리했습니다. 안내 기간·확인 날짜·출처와 감염병 원문 PDF를 연결하고, 홈의 진료시간·오시는 길 위에 최근 안내 3개를 배치했습니다. |
| 심장·혈관 증상 안내 20편 | 가슴통증·두근거림·실신·숨참 등 환자의 질문에서 시작하는 글 20편을 작성했습니다. 위험 신호, 진료 때 전달할 정보, 검사 시 확인할 점을 설명하고 관련 검사·질환 안내로 연결했습니다. 기존 질환 설명 20편도 유지했습니다. |
| 저작권·콘텐츠 이용 안내 | 글과 그림의 링크 공유·인용·재사용 조건을 설명하는 페이지를 만들었습니다. 의료정보 글과 사이트 하단에서도 확인할 수 있게 했으며, 외부 기관 자료는 해당 기관의 이용 조건을 따르도록 안내했습니다. |

작업은 **기존 내용과 비교 → 부족한 자료 제작·원고 작성 → 공식 출처 확인 → 화면 반영 → 사용 점검** 순서로 진행했습니다. 전달 자료에는 개별 이미지와 상세 본문 원고가 없어, 그림은 참고 자료를 바탕으로 새로 제작하고 글은 근거 자료를 확인해 작성했습니다. 삽화는 실제 의료진이나 환자의 사진이 아닙니다.

공지의 경우, 병원 소식을 확인하는 창구를 일관되게 유지하도록 기존 홈페이지의 공지 게시판을 연결했습니다. 개발 중인 홈페이지에는 6개 주제의 요약과 공식 자료를 제공하는 방식으로 반영했습니다.

작업 후 전체 안내 페이지는 **108개에서 129개**로 늘었습니다. 휴대전화·컴퓨터 화면, 이미지 확대, 검색, 페이지 연결과 읽기 편의성을 점검했습니다. 전체 페이지 생성 검사와 브라우저 검사 55개가 통과했으며, 검색 화면의 로딩 속도도 개선했습니다.

**확인이 남은 사항은 두 가지입니다.** 새로 작성한 의료정보의 의학적 내용 검토와, 수원시 대상포진·경기도 학생 독감 지원사업의 현재 본원 접종 가능 여부입니다. 두 사업은 확인 전까지 ‘방문 전 전화 확인’으로 안내했습니다. 개발 완료 후 추가 요청에 따라 9월 28일 [검토용 홈페이지](https://codepump-net.github.io/yt-top-webforai/)에 배포했으며, 실제 129개 페이지의 반영을 확인했습니다. 의료 검토 전이므로 검색 색인 제외 상태를 유지하고 있습니다. 기존 병원 홈페이지에는 변경을 게시하지 않았습니다.
