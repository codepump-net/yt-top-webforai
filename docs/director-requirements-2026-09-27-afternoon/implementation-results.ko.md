## 자료의 출처와 제작 방식

- 개별 원본 그림과 상세 원고는 전달받은 것으로 처리하지 않았다. 실제 제공된 모음판을 참고해 대표 삽화 12종을 새로 생성하고, 20편의 증상 원고와 6주제 요약을 새로 편집했다.
- 삽화는 실제 의료진·환자의 사진이 아니다. [원본 PNG와 생성 프롬프트](../../assets/generated/banners/prompts.json)를 보존했다. 공개 파일은 WebP다. 신장 배너는 콩팥 삽화와 실제 HTML의 ‘신장질환 진료’ 제목으로 제공한다.
- 4개 신규 안내도는 [그림 데이터](../../content/visuals.json)와 [생성 스크립트](../../web/scripts/render-patient-diagrams.mjs)에서 만든 PNG·WebP다. 이미지와 화면의 순서별 설명이 같은 데이터를 사용하며, 설명만 변경하고 그림을 갱신하지 않으면 검사가 실패한다.
- 기존 예방접종 일정표의 파일·크기·9행 HTML 표는 보존했다. 글씨를 읽는 안내도 5종에 키보드·모바일 확대와 원본 이미지 연결을 제공한다. 대표 삽화 12종은 사용자의 후속 의견에 따라 확대 조작 없이 표시한다.
- [이미지 원장](../../content/assets.json)에 크기·바이트·해시·출처를 기록했다. 전체 공개 이미지 22개 중 이번 신규 파일은 16개이며 모두 200 kB 이하다.
- 증상 원고의 근거와 확인일은 [페이지 원장](../../content/pages.json)의 `sources`에, 환자 목적은 [목적 원장](../../content/page-intents.json)에 기록했다. 실제 의료진 검토 기록은 생성하지 않았다.

공식 출처와 PDF의 URL·바이트·SHA-256은 [공지 원장](../../content/notices.json)에 있다. 원문은 해당 기관에서 열거나 내려받도록 연결했다. PDF는 3,655,819바이트이며 다른 주차 파일로 대체하지 않았다.

명단 등재와 현재 접종 가능 여부를 구별했다. 2026-09-28 사용자 답변 ‘두 사업 모두 아직 확인 필요’를 반영해 두 지역사업 모두 전화 확인 문구를 표시한다. 사용자에게 재확인을 요구하며 개발을 중단하지 않았다.

기간이 확정된 사업은 한국 날짜로 시작 전·안내 기간·종료 상태를 구분한다. 종료 후에는 ‘기간이 지난 안내’에 남기고 새로운 사업으로 자동 연장하지 않는다. 종료일이 확인되지 않은 수원시 사업은 임의의 마감일을 만들지 않고 재고·예산 확인을 안내한다. 자바스크립트가 없는 경우에는 빌드 시점의 상태와 명시된 날짜·확인일을 읽을 수 있다.

## 검증 기록

검증 도구와 근거는 `web/reports/`에 생성되며 사이트 출력에는 포함되지 않는다. Node 24.21.0을 사용했다. Python 하네스는 이 환경의 `python3`를 `PYTHON`으로 지정했다.

수정한 문제도 기록한다. 기존 증상 목록 개수 검사(5개)를 25개로 갱신했고, 모든 페이지를 검사하면서 발견한 외국어 전역 푸터 링크 누락을 보완했다. 검색 페이지의 초기 LCP가 약 2.66초로 2.5초 기준을 초과해 검색 자료의 읽기 방식을 바꿨으며, 최종 9개 화면 측정에서 검색 LCP는 약 2.05초였다. 검색 자료 읽기 실패 시 재시도와 전체 페이지 연결도 브라우저에서 검증했다.

최종 성능 결과는 `web/reports/performance-selected.json`, 최종 빌드·정적 검사는 `web/reports/build-manifest.json`·`static-audit.json`, 후속 브라우저 결과는 `web/reports/e2e.json`에 있다. 전체 55개 브라우저 실행과 접두어 실행 결과는 `.local/afternoon-update/verification/`에도 보존했다. 실제 의료진 검토 기록은 여전히 0건이다. SEO 측정의 색인 허용 항목은 검토 모드의 noindex 때문에 통과하지 않으며, 실제 검색 노출 성과를 뜻하지 않는다.

## 확인이 남는 범위

개발 완료는 의료진의 임상 검토나 실제 접종 운영 확정을 뜻하지 않는다. 신규 의료정보의 실제 검토, 두 지역사업의 현재 본원 운영 확인, 기존 홈페이지의 개별 공지 게시 여부·주소 확인은 별도 사실 확인 대상이다. 확인 전에도 환자는 공식 조건과 문의 경로를 읽을 수 있다.

최초 개발 범위에는 배포·통합·기존 홈페이지 게시 작업을 포함하지 않았다. 이후 사용자의 별도 요청에 따라 검토용 GitHub Pages 사이트를 배포했다. [배포 결과와 검증 기록](deployment.ko.md)을 참고한다. 검토 모드의 noindex와 실제 승인 증거를 요구하는 공개 검증을 유지했다. 원자료의 설치·이식 절차는 실행하지 않았으며 기존 병원 홈페이지에는 변경을 게시하지 않았다.
