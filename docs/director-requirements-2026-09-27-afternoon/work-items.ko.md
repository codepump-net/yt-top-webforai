# 요청사항 평가와 개선 작업 목록

> 2026-09-28 개발 결과는 [구현 결과](implementation-results.ko.md)를 참고하세요. 아래는 작업 전 분석 기록입니다.

작성일: 2026-09-27. 작업 전 검토용 내부 문서.

## 범위와 사용법

현재 `plan/`의 9개 자료를 [1차 분석](README.ko.md)에 이어 항목별로 평가했다. **아래의 ‘개선 후’는 목표 상태이며, 구현 완료 상태가 아니다.** 사이트·원본 자료는 변경하지 않았다. 배포, 사이트 통합, 패키지 이식, 특정 컴포넌트 연결 방식은 제외했다. 콘텐츠와 화면의 품질을 확인하는 작업은 포함한다.

작업은 **26개 묶음**으로 정리했다. 이미지 17종·공지 6주제·증상 20주제의 **43개 개별 대상**은 [대상별 작업 전후 명세](scope-register.ko.md)에 각각 기록했다. 묶음 수와 페이지 수는 다르다. 원자료가 제시한 28개 경로는 요청 목록으로 보존하되 전부 신규 페이지로 확정하지 않는다.

- **P0:** 다른 작업의 기준이 되는 자료·내용·사실 확인 또는 확인된 오류 수정.
- **P1:** 환자가 내용을 이해하고 필요한 안내를 찾는 데 직접 필요한 작업.
- **P2:** 이용 안내와 표현의 마무리. 요청 범위에 포함하며 임의로 생략하지 않음.
- **공통 검증:** 각 분야 작업 뒤 수행. 마지막에 한 번만 확인한다는 뜻이 아님.

현재 상태는 저장소의 콘텐츠·화면 코드에서 확인했다. 실제 운영 화면, 외부 지원사업의 최신 조건, 원본에 없는 의료정보를 새로 검증한 결과는 아니다. 현재 원장에는 108개 페이지, 심장·혈관 질환 글 20개, 증상백과 연결 글 5개가 있다. 이 중 심장·혈관 증상 분류에는 기존 두근거림 후속 글 1개가 연결된다. 실제 검토 기록 파일은 비어 있다.

## 진행 순서와 선행 조건

이 순서는 자료·원고·화면을 정리할 작업 순서이며, 전달 패키지의 기술 적용 순서가 아니다.

1. **자료와 대상 정리:** D01·D02, S01. 원고·원본의 유무를 확인하고 기존 글과의 역할을 정한다. 자료가 없어도 현재 내용과 중복 대조는 진행할 수 있다.
2. **정확성 확인:** V01, N01·N04, S06, C04. 확인된 오기와 공지 역할·사업 사실·검토 정보·자료 권리를 정리한다. 원본이 필요한 실제 그림 수정은 확보 후 진행한다.
3. **환자용 내용 준비:** N02·N03·N07, S02·S05, V03·V04. 공지·증상 원고와 그림의 텍스트 설명을 준비한다. 서로 독립인 분야는 한 분야의 미확인 사항 때문에 전부 멈추지 않는다.
4. **화면과 탐색 개선:** V02·V05, N05·N06, S03·S04. 확인된 자료를 기준으로 배치·검색·관련 안내를 완성한다.
5. **이용 안내와 전체 점검:** C01–C03 및 Q01·Q02. 저작권 안내를 마무리하고 각 분야에서 수행한 검증을 모아 누락 여부를 확인한다.

지금 단계에서 가장 먼저 필요한 결과물은 **자료 확보 목록, 20주제의 기존 글 대응표, 공지 6주제의 원문·사실 확인표, 17종 이미지의 배치·오류 목록**이다. 이번 문서와 별첨은 그 작업의 대상과 목표를 정의하며, 원고 확보나 의학적 확인까지 마쳤다는 뜻은 아니다.
