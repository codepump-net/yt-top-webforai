## 4. 심장·혈관 증상 20주제

모든 요청 상세 경로는 현재 원장에 없다. 관련 기존 글은 요청 전체를 이미 충족했다는 뜻이 아니다. 원고가 없어 중복 정도와 독립 글 필요성은 S01에서 최종 판정한다. 원요청의 독립 20편과 달리 기존 글 보완으로 대응할 대안은 조정 필요로 기록하며 임의 생략하지 않는다.

각 행의 공통 완료 기준: 환자 질문에 실제 답변, 제목·요약·메타설명·본문 일치, 근거 있는 위험 신호·검사·의뢰 설명, 출처, 적절한 관련 안내와 공통 안전 안내, 실제 기록에 따른 작성·검토 정보, 분류·검색·전체 목록 연결. 의료 검토 기록 없이 검토 완료를 표시하지 않는다.
