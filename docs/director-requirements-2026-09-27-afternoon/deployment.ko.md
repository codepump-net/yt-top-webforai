## 검사 결과

두 경로 구성에서 각각 콘텐츠·이미지 검사, 정적 페이지 129개, 단위검사 71개, 하네스 17개, 브라우저 검사 55개를 통과했다. 브라우저 검사 누락·실패·재시도 후 통과는 0건이다. lint·타입 검사도 통과했으며 의존성 취약점은 0건이다.

CI 모바일 모의 성능 측정 6개 화면은 두 경로 구성에서 모두 기준을 통과했다. 성능 점수는 96~99점, LCP 최대 약 2,332ms다. 프로젝트 경로 검색 LCP는 2,273ms였다. 이는 자동화된 모의 측정이며 실제 사용자의 성능이나 검색 노출 성과를 의미하지 않는다.

실제 배포 사이트에서는 이미지 22개의 파일 해시 일치, 검색 자료 125개와 새 증상 20편의 검색 연결, 사례 검색 제외를 확인했다. 휴대전화·PC 14개 화면에서 가로 넘침 없이 표시됐고, 홈 최근 공지 3개와 공지 6주제, 두 지역사업의 전화 확인 문구, 검색 결과가 정상이다. 신규 삽화·안내도 16개 확대, 키보드 닫기와 초점 복귀, 자바스크립트 없는 증상 목록·검사 준비 설명도 확인했다. 브라우저 실행 오류는 없었다.

## 유지한 조건

저장소의 기존 `PUBLICATION_MODE=review`를 유지했다. 사이트는 접속할 수 있으며 검색 색인을 요청하지 않는 `noindex` 상태다. 공개 XML 사이트맵은 비어 있다. 의료 검토·검색 공개 승인 기록을 생성하거나 갱신하지 않았고, 기존 공개 승인 검증을 완화하지 않았다.

수원시 대상포진과 경기도 학생 독감 지원사업의 현재 본원 접종 가능 여부는 미확정으로 유지한다. 기존 병원 공지 게시판과 사례 원문 연결도 유지하며 `yttop.co.kr`에는 변경을 게시하지 않았다.

개발 산출물·이미지 원본·작업 보고서를 커밋했다. 작업 전부터 있던 `plan/` 원자료의 추가·삭제는 이번 커밋에 포함하지 않고 작업 폴더에 보존했다. 이 배포 기록과 보고서 갱신은 별도 문서 커밋으로 보관하며 사이트 결과물을 변경하지 않는다.
