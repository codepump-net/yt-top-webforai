# 현재 45개 경로의 페이지별 개선안

현재 `content/pages.json`의 ID·경로를 기준으로 작성했다. **현재 경로 유지**를 기본으로 하며 폐기한 정책·사례 상세·공지 상세 페이지는 복원하지 않는다. A는 첫 집필 묶음, B는 후속 집필, K는 공통 기반·기능 유지 작업이다. 우선순위는 검증된 검색량 순위가 아니다.

`Q01`~`Q13`은 [기존 조사 후보](question-backlog.csv), `F01`~`F18`은 [실제 병원 확인 항목](facts-to-confirm.csv)이다. 표에 추가한 질문은 편집 제안이며 외부에서 관측한 질문 건수에 포함하지 않는다. 각 상세 페이지는 아래 질문을 해결하되 모두 FAQ로 만들 필요는 없다.

## 3. 우선 원고의 구체적인 화면 구성

### 심장초음파·홀터·검사 비교·두근거림 후속 안내

심장초음파는 검사명과 목적을 밝힌 요약으로 시작하고, 평가 범위와 한계, 다른 검사와의 차이, 영통탑 예약·준비·결과 상담 순으로 쓴다. `Q01` 답변은 평가 범위를 설명하는 절에서 완결한다. 검사 비교에는 `Q02`·`Q04`를 배치하고 **검사 / 관찰 대상 / 기록 방식 / 결과 해석 시 함께 볼 정보** 열의 표를 제공한다. 실제 확인이 필요한 장비 시간이나 비용을 비교표에 추정 기재하지 않는다.

홀터 페이지는 실제 착용·생활·증상 기록·반납·결과 설명으로 구성한다. 증상 일지 예시는 빈 양식으로 **증상 시각 / 지속 양상 / 당시 활동 / 의료진에게 전달할 메모** 정도를 제안하고, 필요한 항목은 의료진 검토로 확정한다. 실제 환자 기록은 예시로 넣지 않는다. `Q05`는 결과 상담 절에 둔다.

두근거림 후속 안내는 검사 중 증상 포착 여부, 진료 때 전달할 기록, 이전 결과, 신속한 도움 안내를 한 흐름으로 구성한다. `Q03`에 개인의 정상·이상을 판정하는 답변을 만들지 않는다. 긴급 안내의 조건과 행동은 실제 검토하고, 전화 예약 버튼과의 우선순위를 함께 확인한다.

### 내시경 소개와 준비 안내

위·대장내시경 소개는 **검사 목적 → 병원에서의 상담·검사 절차 → 준비 안내 링크 → 결과 설명 → 비용 확인**으로 구성한다. 조직검사·처치·진정 여부 등은 실제 시행 범위와 조건을 확인한 뒤 포함한다. `Q13`은 위내시경의 진정 관련 확인 절에 두고 대장내시경에서 문맥을 설명해 연결한다.

대장내시경 준비 안내는 **예약할 때 → 안내서를 받을 때 → 검사 전날 → 검사 당일 → 준비가 달라졌을 때** 순서로 구성한다. `Q06`은 단계 구분, `Q07`은 예약 시각, `Q08`은 물, `Q09`는 음식, `Q10`은 음료에 연결한다. 정결제·금식·복약 숫자는 F10 확인 후만 쓴다. 확인 전에도 “예약 시각과 받은 안내서를 준비하여 문의” 같은 구체적인 연락 동선은 제공할 수 있다. 이 상태를 검사별 준비 지침 완성으로 평가하지 않는다.

인쇄 시 질문과 확인표가 읽히도록 기존 인쇄 기능을 유지한다. 안내서 이미지를 사용하게 되면 원본 권리·현재 버전을 확인하고 핵심 안내는 텍스트로 제공한다.

### 국가검진·검진 준비·마약검사·비용

국가검진은 **대상·항목 확인 → 예약 항목 선택 확인 → 준비 안내 → 결과 상담**으로 구성한다. 검진 준비에서는 `Q11`·`Q12`를 사용하여 항목별 준비 차이와 이미 음식·음료를 섭취했을 때 전달할 정보를 설명한다. 검진 대상·주기·제도는 작성 시점 공식 자료로 확인한다.

마약검사는 **제출 목적 / 요구 항목 / 결과지 언어·양식 / 제출 기한** 확인표를 먼저 제공한다. F12의 원본 항목 충돌을 해결한 후 실제 가능한 항목을 쓴다. 비용 페이지는 **항목 / 포함 범위 / 별도 발생 가능 항목 / 적용 조건·확인일 / 문의 경로**로 설계한다. 확인되지 않은 값의 빈칸을 예시 가격으로 채우지 않는다. 과거 이벤트 가격을 현행 총비용으로 재사용하지 않는다.

### 방문 안내

주소·전화·대중교통·지도·주차를 공통 원장에서 출력한다. 시간은 **요일 / 진료 구간 / 휴게 적용 / 별도 접수 안내**로 구분한다. 토요일 점심과 검사 마감은 F02·F03의 확인 결과를 반영한다. 날짜별 휴진은 기존 공지 채널로 연결한다. 확인한 주차장 입구 사진이 있으면 방문 판단에 필요한 곳에만 배치하고, 사진·텍스트·지도 위치를 대조한다.

## 4. 페이지별 원고 인수 양식

각 작업자는 내부 원장에 `pageId`, `questionIds`, `resolvedQuestions`, `claimEvidence`, `clinicFactIds`, `unresolvedItems`, `relatedAnchors`, `actualReviewRecord`를 남긴다. 이들은 **제안한 집필 관리 필드**이며 현재 `pages.json`에 바로 추가할 수 있는 필드가 아니다. 구현은 [데이터 계약 변경 순서](implementation.ko.md)를 따른다.

공개 원고만 읽는 검토자가 다음을 확인하면 해당 페이지의 편집 검토를 마친다.

1. 이 페이지가 누구의 어떤 방문·검사 질문을 해결하는지 명확하다.
2. 핵심 답변을 페이지 안에서 찾을 수 있고, 필요한 경우 적용 조건과 한계가 같은 절에 있다.
3. 다른 페이지와 역할이 구분되며 반복 설명 대신 적절한 관련 안내가 연결된다.
4. 의료 주장·운영 숫자·의료진 표시를 실제 근거로 대조했다.
5. 제작·검수 대기·수요 조사·최적화 실적이 환자 화면에 섞여 있지 않다.

참고 자료를 클릭하지 않아도 기본 설명을 이해할 수 있게 쓴다. 상세한 참고 읽기는 출처 링크로 제공하며, 외부 Q&A 링크를 검증된 의학 근거로 자동 노출하지 않는다.
