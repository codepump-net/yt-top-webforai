# 영통탑내과 AEO·GEO 개선 실행 계획

작성일: 2026-09-11. 상태: **개선 설계 완료 / 사이트 개선 구현·의료 검토·배포는 이 문서 작업에서 수행하지 않음.** 개발·운영 참고 문서이며 병원 홈페이지에 게시하지 않는다.

후속 구현: [실제 개선 반영·전후 비교 결과](../aeo-geo-improvement-results-2026-09-11/README.md). 이 계획의 작성 당시 상태와 후속 실행 결과를 구분해 확인한다.

## 1. 목표와 적용 범위

**기존 국내 의료 Q&A 조사와 병원 자료를 적극 활용하여, 최초 레퍼런스인 더건강한365와 추가 비교한 올림픽파크365의 관찰 표본을 넘어서는 환자 답변 품질과 정보 신뢰성을 갖춘 병원 홈페이지를 만든다.** 실제 검색·AI 인용 성과의 우위는 공개 후 별도로 측정한다. 이 계획을 작성했다는 사실을 최적화 완료나 경쟁 사이트 추월로 보고하지 않는다.

기존 `yttop.co.kr`과 함께 운영하며, 현재 45개 경로를 개선 범위로 삼는다. 병원 소개·진료·검사·방문 안내가 기본 목적이다. 공지와 진단 사례는 기존 원문 채널을 유지한다. 환자에게 읽히는 정확한 설명을 AI도 같은 HTML에서 읽도록 한다. [환자용 콘텐츠 기준](../patient-content-policy.ko.md)을 적용한다.

## 3. 레퍼런스를 넘어설 핵심 전략

**환자가 실제로 어려워한 질문에 병원의 구체적인 답변을 붙인다.** 조사 후보 13개 전부를 집필 작업에 연결한다. 예를 들어 “어떤 검사인가요?”에 머물렀던 심장초음파 설명을 검사 간 차이, 평가 범위, 결과를 이해할 때의 조건, 실제 예약·상담 절차로 확장한다. 다만 외부 개인 상담 답변을 영통탑의 지침으로 복사하지 않는다.

**의학 설명과 병원 운영 사실을 각각 확인한다.** 일반 검사 설명은 해당 근거와 실제 의료진 검토를 연결하고, 예약·준비 안내서·검사 장비·서류·비용은 영통탑의 확인 자료에 연결한다. 타 병원의 금식 시간이나 검사 시간을 추정 적용하지 않는다. 미확정인 숫자 대신 환자가 확인할 대상과 연락 방법을 제공할 수 있으며, 이 경우 상세 답변 미완료 상태는 내부 원장에 남긴다.

**출처와 의료진 표시의 정확성을 비교 기준으로 삼는다.** 레퍼런스에서 관찰한 상세 설명·비교표·저자 연결은 도입하되, 경력 오귀속·운영시간 충돌·주장과 맞지 않는 인용 같은 문제를 재현하지 않도록 검증한다. 기관명과 논문 수만 늘리는 방식으로 합격 처리하지 않는다.

**서비스 안내와 준비 안내를 이어 하나의 환자 동선을 완성한다.** 서비스 페이지는 무엇을 어디서 어떻게 상담하는지 설명하고, 준비 안내는 예약한 환자의 체크리스트를 담당한다. 같은 질문의 대표 답변은 한 페이지에 두며 다른 페이지에서는 짧은 문맥 설명과 해당 절 링크를 제공한다. 질문 변형마다 새 URL을 만들지 않는다.

Google은 AI 검색에도 기본 SEO·본문 접근성·본문과 일치하는 구조화 데이터를 안내하며, 별도의 AI 전용 파일이나 schema를 요구하지 않는다. 이 계획의 질문 설계와 근거 연결은 그 원칙을 병원에 적용한 편집·개발 선택이다. 모든 AI 서비스에 동일한 효과가 검증됐다는 뜻은 아니다. [Google AI 기능 안내](https://developers.google.com/search/docs/appearance/ai-features).

## 4. 실행 순서와 완료 구분

| 순서 | 작업 | 다음 단계로 넘길 결과 |
|---|---|---|
| 1 | 조사 18건·후보 13건 연결, 운영 사실 18묶음 확인 착수 | 질문 대표 경로, 미확정 사실과 근거 목록 |
| 2 | 공통 사실·주장 근거·인물 참조 데이터 계약 확장 | 검증 가능한 원고 구조와 공통 렌더러 |
| 3 | 1차 상세 10페이지와 방문·비용 안내 보강 | 질문별 자체 원고, 출처 대조, 실제 병원 답변 |
| 4 | 나머지 상세 15페이지 및 목록·소개·이용 페이지 정리 | 현재 45경로 전체 개선, 중복 답변과 내부 보고 문구 점검 |
| 5 | 의료·운영 검토, 레퍼런스와 동일 기준 비교 | 표시할 실제 역할과 검토일, 미충족 항목 수정 |
| 6 | production 검사·Actions·Pages 검증, 검색 도구 확인 | 공개 200과 색인 가능성, 실제 색인은 별도 관측 |
| 7 | 공개 후 2·4·8주 반복 측정과 수정 | 신규/기존 URL 인용, 답변 정확성, 환자 방문 동선 변화 |

1차 상세 10페이지는 심장초음파, 홀터, 위내시경, 대장내시경, 국가검진, 마약검사와 건강정보 4편이다. 조사 질문이 연결되는 페이지와 실제 방문 결정에 중요한 페이지를 먼저 선정한 것으로, 검색량 순위가 아니다. 개발 중 병원 확인을 기다리는 항목이 있어도 출처 정리·데이터 계약·다른 페이지 집필은 계속 진행한다. 근거 없이 승인 필드를 채워 일괄 공개하는 방식은 허용하지 않는다.

완료는 세 단계로 보고한다. **제작 완료**는 원고와 구현·검증의 완료, **공개 준비 완료**는 실제 검토와 배포 조건 충족, **성과 우위 확인**은 동일 기준의 반복 관측 결과다. 서로 대체하지 않는다.

## 5. 이번 문서 작업의 경계

현재 `content/`, 웹 앱, noindex 정책, 배포 설정을 이 계획으로 수정하지 않았다. 개인정보·외부 상담 답변 전문·비공개 검토 증빙을 새 문서에 저장하지 않는다. 공개 저장소의 개발 문서와 환자가 보는 웹 출력의 경계는 유지한다.

네이버 조사까지 포함한 기존 자료를 검토했지만, **확보된 지식iN 본문 0건, 검증된 고빈도 묶음 0개, 즉시 게시 승인된 외부 Q&A 0개**라는 상태는 그대로다. 활용할 수 있는 조사 질문 13개를 빠짐없이 독자적인 답변 제작으로 연결하는 것이 이번 계획의 구체적인 출발점이다.

문서 검증에서는 현재 45개 ID·경로의 정확한 대응, 의료 상세 A차수 10개/B차수 15개, 원자료 18개 URL·선정 상태의 일치, 후보 13개의 대표 답변 7페이지 연결, 확인 묶음 18개, 실행 작업 12개의 참조와 순환 없는 의존관계 및 로컬 문서 링크를 확인했다. 모두 통과했으며 의학적 정확성·이용 권리·빈도·성과 인증을 수행한 검사는 아니다. 문서만 변경했으므로 앱 빌드·브라우저 검사를 다시 실행하지 않았다.
