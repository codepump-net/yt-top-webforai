# 기존 국내 의료 Q&A 조사 활용 계획

내부 집필 참고 문서. 기존 조사 메모를 새 홈페이지의 **질문 설계**에 연결한다. 외부 상담 원문을 홈페이지 원고·AI 학습·RAG 데이터로 승인하는 문서가 아니다.

## 확보 자료와 사용 상태

직접 확인한 입력은 로컬 [Q&A 조사 보고서](../../research/2026-09-11-korean-medical-qa/reference.ko.md), [출처 색인](../../research/2026-09-11-korean-medical-qa/data/question-reference-index.json), [집계](../../research/2026-09-11-korean-medical-qa/data/selection-summary.json), [검증 결과](../../research/2026-09-11-korean-medical-qa/data/verification.json)다. `research/`는 공개 저장소에 포함되지 않으므로 이 계획에는 출처 URL·선정 결과·활용 경로만 남긴다.

| 자료 | 실제 확보 내용 | 이번 활용 |
|---|---|---|
| 네이버 지식iN 관련 조사 | 접근 제한과 검색 결과의 한계 기록; 검증된 질문·답변 본문 없음 | 네이버 데이터 확보 완료로 표기하지 않음. 승인된 데이터 경로가 마련되면 별도 추가 |
| 하이닥 | 15개 URL: 질문 후보 13개, 제외 2개 | 후보 전부를 질문 작업표에 연결; 외부 답변의 문장·개별 진단은 이전하지 않음 |
| 닥터나우 | 3개 URL 모두 제외 | 작성자 불명·AI 답변·답변 부재를 배제하는 선별 기준으로 활용 |
| 전체 | 18 URL, 중복 통합 17그룹, 후보 13개, 제외 5개 | “병원 관련 전국 질문의 전체 수”나 “환자 17명”으로 해석하지 않음 |
| 영통탑 직접 언급 Q&A | 확인 0건 | 외부 의사의 상담을 영통탑의 진료 실적·후기로 표시하지 않음 |
| 고빈도 및 게시 승인 | 고빈도 검증 0묶음, 승인된 Q&A 0건 | 후보 선정과 원고 승인·빈도 판정을 분리 |

기존 조사에서 데이터셋 이용 권리와 의료 검토가 미확보 상태임을 확인했다. 이 문서는 당시 이용 조건을 확대 해석하지 않는다. 추가 자동 수집·원문 저장을 실제 구현할 때 해당 서비스의 현행 허용 범위부터 다시 확인하며, 기존 접근 제한을 우회하는 수집기는 계획에 포함하지 않는다. 질문 주제 탐색에는 기존의 짧은 조사자 메모와 원문 링크를 사용한다.

## 13개 질문 후보의 실제 배치

전체 원장은 [question-backlog.csv](question-backlog.csv)다. `Q01`~`Q13`은 자체 집필 후보, `X01`~`X05`는 제외 기록이다. 한 후보마다 대표 답변 페이지를 하나 지정했다. 다른 페이지는 관련 안내로 연결하며 별도의 독립 수요로 다시 세지 않는다.

| 질문 묶음 | 원자료 URL / 질문 후보 | 대표 답변을 강화할 경로 | 레퍼런스보다 높일 부분 |
|---|---:|---|---|
| 심장초음파 | 2 / 2 | 심장초음파, 심장검사 비교 안내 | 검사가 답하는 질문과 답하지 못하는 질문을 구분하고 결과 간 차이를 설명 |
| 홀터 | 4 / 3 | 홀터, 심장검사 비교, 두근거림 후속 안내 | 실제 장비·기록·결과 설명 절차와 검사 중 증상 포착 여부를 연결 |
| 대장내시경 준비 | 9 / 5 | 대장내시경 준비 안내 | 음식·물·커피·검사 시각의 질문을 구분하고 영통탑 예약 안내서에 연결 |
| 검진·진정 내시경 준비 | 3 / 3 | 검진 준비, 위내시경 | 일반 검진과 진정 검사를 구별하고 검사 조합에 맞는 확인 동선 제공 |

질문 후보가 13개라는 이유로 FAQ를 13개 더 복제하지 않는다. 예를 들어 `Q06`~`Q10`은 대장내시경 준비 페이지의 식사·예약 시각·물·음료 절에서 각각 해결할 수 있다. 본문에 완전한 답변이 있으면 FAQ에는 추가 궁금증을 다루거나 해당 절로 연결한다. 현재 스키마의 페이지당 질문 상한 8개 안에서도 충분히 설계할 수 있다.

## 질문에서 자체 답변까지의 편집 절차

1. 후보의 주제를 환자가 이해하는 검사명과 상황으로 다시 쓴다. 원 질문자의 나이·검사 수치·개인 사연·닉네임·날짜를 답변 원고에 가져오지 않는다.
2. 질문 하나를 일반 의학 설명, 병원 운영 사실, 개인별 판단으로 나눈다. 개인별 판단은 홈페이지가 확정할 수 있는 설명 범위를 정하고 진료 때 필요한 정보로 연결한다.
3. 의학 설명은 기관·학회·공식 검사 안내 등 해당 주장에 맞는 자료로 대조한다. 특정 환자 답변의 전문의 표시만으로 일반 지침을 승인하지 않는다.
4. 병원별 설명은 [사실 확인표](facts-to-confirm.csv)의 안내서·현재 운영 확인을 사용한다. 예컨대 타 병원의 장 정결제 복용량이나 검사 시간이 영통탑에서 동일하다고 추정하지 않는다.
5. 독립적인 원고를 작성하고 문장별 근거·적용 조건을 내부에 연결한다. 환자 화면에는 해당 설명과 필요한 출처·확인 방법만 제공한다.
6. 실제 검토자의 수정 사항을 반영한 뒤 정확한 이름·역할·검토일을 표시한다. 외부 Q&A의 의사를 병원 의료진 또는 원고 검토자로 등록하지 않는다.
7. 대표 답변 페이지와 관련 페이지에서 서로 모순이 없는지 확인한다. 검색 결과와 AI가 짧게 추출해도 검사명·적용 조건·한계가 남는지 사람도 읽어본다.

### 이미 확보한 의학 참고 자료의 역할

아래는 기존 조사에서 확보한 출처 후보다. **이번 계획에서 새 원고의 모든 의학 주장을 검증한 것은 아니다.** 집필 시 원문·갱신 시점·적용 범위를 다시 확인하고 부족하면 해당 분야의 자료를 추가한다.

| 출처 후보 | 사용할 검토 범위 | 추가 확인 |
|---|---|---|
| [서울아산병원 심장초음파 안내](https://www.amc.seoul.kr/asan/healthinfo/management/managementDetail.do?managementId=516) | 검사 종류·목적·평가 범위의 설명 대조 | 영통탑의 실제 검사 종류, 검사 간 차이에 대한 근거 |
| [서울대학교병원 서맥 안내](https://www.snuh.org/health/nMedInfo/nView.do?medid=AA001378) | 서맥 평가에서 기록 검사의 위치 | 모든 두근거림·빈맥으로 확대하지 않고 일반 부정맥 근거 추가 |
| [서울아산병원 진정 대장내시경 안내](https://health.amc.seoul.kr/health/personal/checkInformation.do?checkno=12) | 준비·진정 관련 검토 항목 파악 | 영통탑 정결제·금식·보호자·귀가 안내서 |
| [영통탑 국가검진 기존 안내](https://yttop.co.kr/31) | 기존 병원 제공 검진 목록의 출발점 | 현재 시행 항목과 국가검진 제도는 집필 시 공식 자료로 재확인 |

기관 자료의 문장을 복제하는 방식으로 원고를 채우지 않는다. 출처 링크는 어떤 설명을 확인할 수 있는지 표시한다. 논문이 필요한 효능·통계 주장은 환자군·비교 대상·결과·기간·분모까지 검토하고, 근거가 부족하면 그 주장을 쓰지 않는다.

## 빈도 데이터를 적극 보완하는 방법

기존 표본은 검색어를 먼저 정한 선택 표본이다. 주제별 건수는 **수요 탐색 신호**이며 고빈도 순위가 아니다. 후보는 빈도 검증을 기다리지 않고 유용성·의료적 중요성·진료 관련성을 근거로 제작할 수 있다. 게시 제목은 “검사 전 궁금한 점”처럼 쓰고, 근거 없이 “영통탑 환자가 가장 많이 묻는 질문”이라고 쓰지 않는다.

| 관측 채널 | 얻을 수 있는 신호 | 집계 방법과 한계 |
|---|---|---|
| 병원 전화·접수 문의의 비식별 주제 집계 | 영통탑 환자의 실제 준비·예약 질문 | 가능해진 시점부터 4주 단위로 시작; 문의 사건 단위 중복 제거, 전체 분모·기간 기록 |
| 사이트 내 검색 | 사이트 이용자가 찾지 못한 안내 | 구현 시 원문에 건강정보가 포함될 수 있으므로 검색어 전문 수집을 기본값으로 켜지 않음; 분류된 주제 집계부터 설계 |
| Search Console·네이버 제공 검색 보고서 | 해당 사이트로 이어지는 검색어·노출 신호 | 실제 계정에서 제공하는 필드만 사용; 검색 노출을 독립 환자 질문 수로 바꾸지 않음 |
| 허용된 외부 Q&A 관측 | 병원 밖의 반복 질문 주제 | 플랫폼별 기간·대상·수집 범위 기록; 중복 확인 불가한 플랫폼은 합산하지 않음 |

수요 기록에는 `channel`, `periodStart`, `periodEnd`, `populationDefinition`, `topicId`, `independentCount`, `eligibleTotal`, `dedupMethod`, `selectionMethod`를 둔다. 값이 없으면 null이다. 기존 보고서의 “12개월 20건·3개월 이상 관찰·상위 25%”는 과거 **제안 기준**일 뿐 이번 자료가 통과한 기준이 아니다. 새 자료의 관측 범위와 표본 크기를 보고 공개 전에 판정 규칙을 고정한다. 짧은 자체 문의 집계를 전국 고빈도 증명으로 확대하지 않는다.

우선순위 조정은 빈도만으로 하지 않는다. 안전상 중요한 질문, 실제 예약을 막는 질문, 영통탑만 답할 수 있는 질문도 우선한다. 확보한 13개 외에 추가한 페이지별 질문은 [페이지 개선안](page-plan.ko.md)에서 편집 제안으로 취급하며 외부 관측 질문으로 수를 부풀리지 않는다.
