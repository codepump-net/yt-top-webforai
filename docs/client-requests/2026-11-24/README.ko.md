# 2026-11-24 11월 원고 반영과 공개 전 확인 사항

이번 후보는 기존 글 23편 개정, 암 예방 글 1편 신규 등록이다. 전체 경로는 136개이며 133개가 production 승인 후 색인 대상이다. 첨부 원본 6개는 로컬에 보존하고, 환자용 본문은 사이트의 콘텐츠 원장과 공통 템플릿으로 내보낸다.

후속 전수 대조와 바로잡은 문구는 [원고 24편 의도 대조 검토](final-review.ko.md)에 기록했다.

| 원고 | 적용 경로 |

표시용 원고에서 `최종 검토일`과 `의학적 최종 검토일` 날짜 줄을 제외했다. 원고의 작성·검토자와 병원 운영정보 반영일이 들어 있는 블록은 승인 근거와 함께 추후 확인하는 대상으로 남겼다. 진료시간·연락처·안전·콘텐츠 이용 안내는 기존 공통 표시를 사용한다. 변경일 메타데이터와 기존 상단의 `내용 수정일`은 11월 24일 실제 편집을 반영한다.

첨부 JSON에서 누락된 소제목·순서 목록·암 예방 FAQ를 원고 미리보기에서 복원했다. 혈압·판막 표는 사이트의 표 구조를 사용하며, 기침·복통·항암치료 중 발열은 기존 환자 FAQ와 관련 링크를 보존했다. 가족력 글은 증상처럼 읽히는 초안 문구를 정리하고 기존 가족력 평가 안내를 바탕으로 FAQ를 구성했다. 흉부 증상·맥박 이상에서는 즉시 도움을 받아야 할 안내가 당일 내원 권고와 섞이지 않도록 편집했다.

원본 출처 중 ACC의 급성관상동맥증후군 및 일차 예방 404 링크와 잘린 CHEST 기침 지침 주소는 공식 저널이나 원문 보관처로 교체했다. 암 예방 참고목록은 구체적인 장을 찾을 수 있는 주소가 없는 교과서 사이트 첫 화면을 제외했다. 자동 요청에서 일부 기관 링크는 403/시간 초과를 반환했다. 새 원고에서 가져온 출처에는 원본의 일괄 확인일을 승계하지 않았다.

## 공개 전 확인 사항

- 변경한 24편의 실제 의료·운영 검토 완료 확인. 혈압 글의 이완기 수치가 기존 120에서 110으로 바뀌는 내용과 가정 재측정 문구, 판막별 추적·의뢰 기준, 항암치료 중 발열 연락 기준과 진료 범위를 우선 확인한다. 국내 혈압 기준은 [대한고혈압학회 진료지침 위원회 발표문](https://www.clinicalhypertension.org/DOIx.php?id=10.5646%2Fch.2026.32.e31)과 대조했다. 새 원고에서 설명한 검사·의뢰는 현재 운영 범위와 대조할 대상이다.
- 별도 보완을 예고한 [암 치료 중 증상별 대처와 위험 신호](../../../content/pages.json)의 교체 본문 또는 구체적인 변경 지시 수령. 발열 안내 개정은 별도의 기존 URL에 반영했다.
- 개정본은 로컬 review 모드로 검증한다. 기존 공개 확인은 기존 버전에 연결돼 있다. 확인 시각과 원장의 유효성 검사를 거쳐 공개한다.

- Chromium의 320·390·1440px 화면에서 혈압·판막 표, 암 예방 FAQ와 검색을 확인했다. 기존 주소와 관련 링크 목록은 개정 23편에서 유지했다.
- 전체 브라우저 검사에서 검색 순위 회귀 1건을 발견했다. 전실신 글의 요약과 소제목을 수정한 뒤 관련 브라우저 검사 10개를 다시 실행해 모두 통과했다. production 전용 분석 검사 1개는 review 모드에서 건너뛰었다.
- 현재 24편의 검토 상태는 `pending`이다. production 계약은 승인 범위 차이·검토 상태·승인 대상 버전 불일치로 현재 후보를 거절했다.
