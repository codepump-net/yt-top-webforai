## 검증 근거

- 단위 검사 108개, 타입 검사와 루트·저장소 하위 경로의 정적 검사 각 136경로가 통과했다.
- 수정 후 전체 브라우저 검사 71개가 통과했다. production 전용 분석 검사 1개는 review 모드에서 건너뛰었다.
- 로컬 HTTP로 읽은 24개 글이 정적 출력의 해시와 일치했다. FAQ 66개, 표 2개, 기존 상단 수정일 20개를 확인했다. 24편의 구조화 데이터에는 실제 `dateModified`가 있고, `lastReviewed`와 `reviewedBy`는 표시되지 않는다.
- 이번 24편에 쓰인 외부 출처 URL 94개를 요청해 78개에서 200 응답을 받았다. 14개는 403, 2개는 연결 종료를 반환했다. 후자의 두 문헌은 [만성기침 지침 원문](https://pmc.ncbi.nlm.nih.gov/articles/PMC6182199/)과 [고혈압 지침 원문](https://pmc.ncbi.nlm.nih.gov/articles/PMC13197191/)으로 별도 확인했다. 자동 요청에서 제한을 받은 링크의 모든 사용자 환경에서의 접근 여부는 확인이 필요하다.

## 후속 수정

- 전실신과 숨참·부종 글에서 예전 `#evaluation`과 현재 `#section-5`가 같은 검사 안내로 연결된다. 두 주소는 자바스크립트 없이 동작한다.
- 전실신의 낙상 예방 문단은 11월 개정 전 공개본에서 확인한 기존 승인 문구를 그대로 복구했다.
- ‘페이지를 찾을 수 없음’을 반환하는 판막 교체 참고 링크는 제거했다. 판막질환 관련 나머지 참고자료는 이어서 이용할 수 있다.
- 국가암검진과 암 가족력 안내의 관련 글에 암 예방 생활수칙을 추가했다. 신규 글에 있던 두 안내로의 링크와 함께 양방향 이동을 제공한다.
