# 0002. 의뢰자 요청 자료를 별도 폴더에 모아 관리

상태: 채택. 결정일: 2026-11-16. 근거: 사용자가 날짜가 적힌 기존 docs 폴더들을 의뢰자의 요청서로 설명하고 별도 폴더에 모아 달라고 요청했다.

## 결정

`docs/` 바로 아래에 있던 날짜 포함 폴더 26개를 **`docs/client-requests/`** 아래로 이동한다. 원래 폴더명과 요청별 하위 구성을 유지하고, 요청서와 해당 요청의 계획·검토·반영·검증 자료를 함께 보관한다. [요청 자료 색인](../client-requests/README.md)에서 모든 폴더를 안내한다.

주제별 현행 개발 문서와 강의 자료는 기존 위치에서 관리한다. 새 날짜별 의뢰자 요청도 `client-requests/` 아래에 접수한다. [0001](0001-documentation-layout.ko.md)의 주제별 문서 구조는 유지하고 날짜별 자료를 docs 루트에 남기는 부분을 대체한다.

## 경로와 기록 보존

Markdown·HTML의 탐색 링크와 현재 테스트·자료 처리 스크립트의 참조를 새 경로로 바꾼다. 이동한 스크립트는 저장소 루트 계산과 의존성 경로를 함께 수정한다. 과거 JSON·로그·CSV·이미지 등 원시 증거의 내용과 해시는 유지한다. 이 증거에 담긴 당시 경로 문자열은 실행 이력으로 보존하며, 필요한 도구는 읽을 때 현재 경로로 해석한다.

## 검증

폴더·파일 이동 누락, 기존에 유효했던 문서 링크의 대상 보존, 원시 증거 무결성, 경로를 읽는 기존 회귀 검사, 콘텐츠·정적 출력 경계를 확인한다. 환자용 원고·공개 확인 기록을 폴더 정리 때문에 갱신하지 않는다.
