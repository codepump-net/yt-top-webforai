# 의사결정 기록

ADR은 기능·아키텍처·운영 경계를 바꾸는 결정의 배경과 이유를 보존한다. 일상적인 문구 수정이나 모든 커밋을 별도 ADR로 만들 필요는 없다.

| 번호 | 결정 | 상태 |
|---|---|---|
| 0001 | [현행 문서와 날짜별 증거를 분리한 docs 구조](0001-documentation-layout.ko.md) | 보관 위치는 0002로 일부 대체 |
| 0002 | [의뢰자 요청 자료를 별도 폴더에 모아 관리](0002-client-request-collection.ko.md) | 채택 |

새 기록은 [ADR 템플릿](../templates/adr.ko.md)으로 만든다. 과거 구조의 선택 이유를 문서 없이 추측해 ‘당시 결정’으로 만들지 않는다.
