# 영통탑내과 블로그 미반영사항 작업 결과 보고서

기준일: 2026년 9월 27일 · 내부 공유용

최초 구현 요약에 후속 검색 성능 보완과 배포 결과를 추가했습니다. 상세 이력은 [배포 기록](deployment.ko.md)을 참고하세요.

원장님이 전달한 **「블로그 미반영사항 통합반영안」의 콘텐츠·화면·검색 개선을 사이트에 반영**했습니다. 이식 패키지와 자동 적용 절차는 작업 대상에서 제외했습니다.

| 작업 항목 | 반영 결과 |
|---|---|
| 진료분야와 하위 안내 | 진료분야를 8개 카드로 정리했습니다. 소화기 5개, 갑상선·경동맥·목 멍울 3개, 신장 3개의 하위 안내를 연결하고 급성 복통 진입 링크를 별도로 배치했습니다. 간질환은 기존 안내를 활용했습니다. |
| 검사·진료 설명 | 심장 관련 혈액검사의 제목과 관련 링크를 정리하고 기존 검사별 결과 시간을 유지했습니다. CART BP Pro 24시간 혈압검사 안내를 추가하고, 복부·장관·경동맥초음파 설명과 금연·체중관리 안내를 보완했습니다. |
| 예방접종 | 제공된 2026년 일정표 이미지를 최적화해 배치하고, 같은 내용을 읽을 수 있는 9개 백신의 HTML 표와 상담 안내를 추가했습니다. |
| 검색·백과 탐색 | 홈 검색창과 헤더의 ‘검색’ 표시, 전체 및 7개 분야 필터, 환자용 별칭 검색을 반영했습니다. 기존 심장·혈관 20편이 백과·검색·사이트맵에서 일관되게 연결되도록 정리했습니다. |
| 목차·공통 안내 | PC·모바일 목차를 하나로 통합하고 최대 8개 항목만 표시했습니다. 빈 목차를 제거하고, 페이지 성격에 따른 기존 안전·예약·서류 안내를 보완했습니다. |
| 환자 사례·개인정보 | 사례를 내부 검색·사이트맵·관련 글·사례 목록 구조화 데이터에서 제외하고 검색 노출 제한을 적용했습니다. 기존 병원 사례 원문 링크 25개는 유지하고 개인정보 공개 금지 원칙을 추가했습니다. |

**작업 규모:** 기존 94개 경로를 유지하면서 14개를 추가해 총 108개 경로(404 포함)로 구성했습니다. 기존 페이지 23개를 수정했으며, 질문·답변 152개는 유지했습니다.

**개발 결과 검토:** 현재 콘텐츠와 렌더러가 검증 완료본과 일치하는 것을 확인했습니다. 주요 분류 수, 예방접종 표, 사례 제외 및 원문 링크 유지도 다시 대조했습니다. 기존 검증 기록상 빌드·정적 검사·단위 테스트 68개·하네스 검사 17개, 루트 및 서비스 하위 경로의 브라우저 검사 각 48개를 모두 통과했습니다. PC·모바일 화면과 검색·목차·메뉴·인쇄 동작을 확인했으며, 로컬 모바일 성능 점수는 홈 99점·예방접종 98점입니다.

**남은 확인과 현재 상태:** 새 원고의 의학적 표현, 실제 검사·백신 제공 범위, 결과 안내 시간 및 금연치료 운영 내용에 대한 의료·운영 최종 검토가 필요합니다. 후속 요청에 따라 기존 `main`에서 커밋·푸시·배포를 완료했으며, 현재 사이트는 `review/noindex` 상태입니다. 새 브랜치 생성·전환과 이식 스크립트 실행은 하지 않았습니다.

**배포 확인:** 검색 첫 화면의 불필요한 처리와 중복 데이터를 줄인 최종 커밋 `ab3ee5e`가 CI 검사와 배포를 통과했습니다. 실제 108개 경로의 HTML 일치와 PC·모바일 주요 화면 14개를 확인했습니다. CI 성능 표본은 97~99점이며 검색 페이지도 기준을 통과했습니다.
