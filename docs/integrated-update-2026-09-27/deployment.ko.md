# 통합반영안 작업 의도 확인 및 배포

기준일: 2026-09-27. 사용자의 후속 요청에 따라 작업 의도를 확인하고 개발 결과의 커밋·GitHub Pages 배포를 진행한다.

## 작업 의도 확인

통합반영안 MD·DOCX와 앞선 이식 README 검토 기록에서 확인되는 목적은 진료분야 구조, 콘텐츠 탐색, 예방접종 시각자료, 조건부 공통 안내, 단일 목차와 사례 노출 정책을 일관되게 반영하는 것이다. 브랜치 생성이나 패키지 자동 적용은 이 목적을 구현하기 위한 필수 기능이 아니다.

현재 작업 폴더에는 통합반영안 MD·DOCX만 있으며, 이전에 검토한 이식 README와 실제 패키지의 스크립트·원고·설정 파일은 없다. 따라서 패키지 코드의 동작을 검증하거나 실행했다고 주장하지 않는다. 제공된 요구사항은 기존 콘텐츠 계약과 컴포넌트에 맞춰 반영했으며, 검토 기록에만 있는 추가 증상 원고 3편은 원문·ID·경로가 제공되지 않아 임의로 생성하지 않았다.

현재 구현을 다시 대조하여 진료분야 8개, 소화기 5개·갑상선/경동맥/목 멍울 3개·신장 3개 하위 안내, 예방접종 표 9개 항목, 사례 검색·사이트맵 제외와 원문 링크 25개 유지를 확인했다. 콘텐츠·렌더러 digest는 앞서 단위 테스트 68개, 루트·프로젝트 경로별 브라우저 테스트 48개를 통과한 편집본과 동일하다. 배포 전 의존성 감사는 취약점 0건이다.

## 배포 범위와 설정

기존 `main`에서 사이트 코드·콘텐츠·검사·내부 보고서를 커밋한다. 작업 전부터 있던 `plan/` 파일 삭제·추가 상태는 이번 개발 결과 커밋에 포함하지 않는다. 새 브랜치를 만들거나 전환하지 않는다. 실제 사이트에는 기존 워크플로대로 `web/out/`만 배포한다.

저장소 변수 `PUBLICATION_MODE=review`를 확인했다. 의료·운영 검토나 검색 공개 승인을 새로 받은 것으로 처리하지 않고, noindex 및 빈 공개 XML 사이트맵을 유지한다. 기존 승인 검증과 의료 검토 기록은 그대로 둔다.

배포 대상: [영통탑내과](https://codepump-net.github.io/yt-top-webforai/). 배포 결과는 해당 커밋의 Actions 검사, Pages 배포, 실제 HTML 일치 검증이 끝난 뒤 아래에 기록한다.
