# 요구사항과 실제 문구의 대조

## ‘원장님이 이렇게 요청했는가’에 대한 답

**특정 안전·예약·서류·저작권 안내는 명시적으로 요청됐습니다. 그러나 개별 질문의 답을 대부분 문의나 주의문으로 대체하라는 요청은 확인되지 않았습니다.** 필요한 주의가 있다는 이유만으로 본문에서 제공할 수 있는 정보를 생략하는 것은 요청 충족으로 볼 수 없습니다.

현재 `plan` 문서, 제목·경로 CSV, 이미지 배치 HTML, 17개 시각자료 참고 이미지와 Git HEAD에 남아 있는 기존 공통 안내문·질환 원고를 대조했습니다. 배포·통합·적용 순서 지시는 이번 콘텐츠 평가 기준에서 제외했습니다. 삭제 상태인 기존 `plan` 파일은 되살리지 않고 Git에 보관된 자료를 읽었습니다. 필요한 인용은 [출처 발췌](requirements-evidence.ko.md)에 남겼습니다.

| 자료에서 확인한 요구 | 현재 결과 | 판단 |
|---|---|---|
| 모든 의학정보 글의 공통 안전 안내 | 해당 안내가 출력되고 전역 하단·본문·그림에도 유사 제한이 반복됨 | 안전 안내 자체는 요청 사항. 중복 금지 취지와 독자가 읽는 순서를 반영하지 못한 부분은 F134 등에서 수정 검토 |
| 심장초음파·홀터 전화 예약과 취소·미방문 정책 | 정책 문구가 하단에 있음 | 개발자가 임의로 만든 회피 문구로 분류하지 않음. 원 요청의 운영 정책 |
| 신분증·제출기관 원본 양식·제3자 수령 요건 | 공통 하단에 안내됨 | 필요한 조건. 개별 검진의 발급기간까지 답하지 않아도 된다는 뜻은 아님 |
| 질환백과 심장·혈관 20편 | 제공 Word에 있던 반복 검사·약물·추적·전원 문구를 각 글에 유지 | 문구의 출처는 원고. 질환별 핵심보다 공통 주의가 앞서는 문제와 일괄 결론은 웹 편집에서 검토해야 함 |
| 심장·혈관 증상백과 20편 | 페이지·제목은 있으며 20편 모두 동일한 결과 상담 문단이 붙음 | 수량과 경로 생성은 완료돼도 제목별 질문에 충분히 답했는지는 별도. F113~F125 |
| 실용형 안내도 5개 | 이미지와 접근 가능한 설명은 있지만 실제 준비·회복 단계 일부가 ‘안내 확인’으로 채워짐 | 그림 존재만으로 실용적인 설명 요구를 충족했다고 판단하기 어려움. F129~F131 |
| 공지·예방접종 6개 주제 | 공지는 있으나 카드의 핵심 정보 부족, 감염병 자료 해설 누락 | 대상·일정·자료 핵심을 직접 설명해야 함. F127·F128 |
| 두 지역 지원사업 참여 확인 전 가능 단정 금지 | 본원 참여가 미확인임을 안내 | 사용자의 후속 답변도 미확인. 이 부분은 유지 |
| 저작권 페이지·글 하단 짧은 문구·전역 링크 | 해당 구조가 있음 | 요청에 포함됨. 의료적 제한을 추가 반복하는 부분은 별도 F126 |

현재 자료에는 증상백과 20편의 제목·경로 목록이 있지만 별도 원본 본문 패키지 전체는 없습니다. 따라서 증상 본문 문장마다 누가 처음 썼는지까지 단정하지 않았습니다. 질환 Word 원고의 40자 이상 연속 일치 문구만 ‘제공 원고와 일치’로 기록했습니다. 짧은 용어가 같다는 이유로 출처를 인정하지 않았습니다.

## 자동 검사로 놓친 부분

코드의 의도를 추측하기보다 현재 검사 조건과 실제 결과를 비교했습니다.

- [공개 콘텐츠 검사](../../web/scripts/public-content-policy.mjs)는 내부 보고 문구 금지, 페이지 목적 기록의 존재·길이, 원문 링크 구조 등을 확인합니다. 제목의 질문에 답했는지까지 판정하지 않습니다.
- [추가 콘텐츠 검사](../../web/scripts/patient-additions-contract.mjs)는 문구 길이, 그림 단계 수, 자산·날짜·해시와 일부 금칙어 등을 확인합니다. 문단이 실제 준비 방법을 설명하는지, 문의 목록만 반복하는지를 검증하지 않습니다.
- [페이지 목적 기록](../../content/page-intents.json)의 129개 중 102개는 해당 페이지 도입 또는 검색 설명과 완전히 같습니다. 요구하는 환자의 질문을 독립적으로 정의하지 않으면 기존 문구를 그 자체의 완료 기준으로 삼게 됩니다.
- 152개 FAQ는 화면과 구조화 데이터의 답변이 일치합니다. 회피적인 답도 그대로 양쪽에 들어갑니다. 형식 일치 검사를 통과했다는 이유로 답변의 유용성이 검증되는 것은 아닙니다.
- 공통 안내 구성요소가 한 번만 출력돼도 본문·전역 하단·그림에서 같은 취지의 문장을 반복할 수 있습니다. 구성요소 수 검사와 실제 독서 경험의 중복 검토를 구별해야 합니다.

기존 검사들은 경로·파일·출처·배포 무결성 확인에 계속 필요합니다. 여기에 페이지의 질문, 실제 답, 조건, 다음 행동을 읽고 판단하는 편집 검토가 추가돼야 합니다. 이번에는 검사 코드를 변경하지 않았습니다.

## 후속 편집에서 사용할 판단 기준

| 판단 질문 | 충족하지 못할 때 할 일 |
|---|---|
| 제목이 묻는 질문에 첫 문단 또는 핵심 표가 답하는가? | 제목과 본문 범위를 맞추고 답을 먼저 작성 |
| ‘확인하세요’ 앞에 확인할 사실·기준이 있는가? | 기존 사실을 가져오거나 내부 정보 확보 과제로 전환 |
| 의료적 변수가 무엇인지 설명하는가? | ‘개인마다 다름’에 그치지 않고 실제로 달라지는 조건을 명시 |
| 주의 문장은 필요한 행동과 이유를 알려주는가? | 독자의 동기를 추정하는 훈계 대신 이유와 행동을 설명 |
| 이 문단이 다른 검사·질환 이름으로 바뀌어도 그대로 성립하는가? | 해당 페이지에서만 필요한 내용으로 구체화하거나 공통 안내로 통합 |
| 제목·요약·본문·FAQ의 정보 범위가 같은가? | 요약의 과한 약속, 본문에만 있는 답, 모호한 FAQ를 함께 수정 |
| 사실이 확인됐는가? | 확인되지 않은 가격·시행 범위·의학 수치·지원사업 참여를 만들지 않음 |

새 문구를 실제 공개하기 전에는 이번 항목별로 변경 전·후를 대조해야 합니다. 특히 의료진 확인이 필요한 준비·회복 시각이나 치료·추적 기준은 일반적인 문장 수정과 구별합니다. 이 보고서는 검토 결과이며 의료 승인이나 공개 승인 기록이 아닙니다.
