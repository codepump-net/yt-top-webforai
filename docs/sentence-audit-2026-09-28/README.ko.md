## 검토 결론

**구체적인 정보를 제공해야 할 자리에 “확인하세요·문의하세요·판단하지 마세요”를 배치한 문제가 여러 페이지에서 반복됩니다.** 제목과 질문은 답을 약속하지만 본문은 상담 준비나 주의사항으로 끝나는 경우가 있습니다. 필요한 정보를 다른 문단에 이미 적어 놓고도 FAQ에서는 다시 문의하도록 한 경우도 확인했습니다. 문구를 공손하게 바꾸는 수준을 넘어 페이지별 답변 구조를 다시 편집해야 합니다.

다만 원장님이 주의 문구를 전혀 요청하지 않았다고 말하는 것도 사실과 다릅니다. 제공된 공통 안내문에는 의료 안전·심장검사 예약·서류 준비 안내가 명시돼 있고, 심장·혈관 질환 20편 Word 원고에도 반복 주의문이 있습니다. **그 요청이 모든 본문과 FAQ를 방어적인 표현으로 작성하라는 뜻은 아닙니다.** 제공 자료에서 그러한 포괄적 지시는 확인하지 못했습니다. 출처와 적용 범위를 구분하지 않고 중복·위계를 조정하지 않은 부분은 사이트 편집상의 문제입니다.

## 개선 작업의 순서와 완료 기준

1. **이미 있는 답부터 되살립니다.** 같은 페이지나 검증된 관련 페이지에 있는 검사 시간·시행 범위·준비물을 FAQ와 도입에서 직접 답합니다. F003~F018, F036, F057~F075 등이 해당합니다.
2. **내용이 비어 있는 안내는 실제 정보를 확보합니다.** 내시경 준비·퇴실 지침, 본원 장비 사용법, 발급·비용·주차 조건 등은 확인할 항목을 내부 작업 목록으로 넘기고 환자에게 반복해서 떠넘기지 않습니다. 확보 전 숫자나 조건을 만들지 않습니다.
3. **페이지별 설명 순서를 다시 구성합니다.** 질문에 대한 답 → 이해에 필요한 이유 → 적용 조건·예외 → 필요한 행동 순으로 편집합니다. 급성 위험 상황은 행동 안내를 가장 앞에 둡니다. 진료·검사 허브는 실제 차이와 선택을 도와야 합니다.
4. **일괄 추가한 문단과 경고를 조정합니다.** 증상 20편·질환 20편·검사별 공통 문단·하단·그림을 함께 보며 중복을 제거합니다. 안전정보는 상황과 이유를 설명하는 위치에 남깁니다.
5. **검색 설명도 실제 답을 요약합니다.** 제목·요약·FAQ·구조화 데이터가 같은 사실을 설명하게 하되, 같은 추상 문구를 여러 곳에 복제하는 것으로 완료 처리하지 않습니다.
6. **완료 판정을 문장 내용으로 합니다.** 페이지를 처음 읽는 사람이 제목의 질문에 답할 수 있는지, 무엇을 해야 하는지, 어떤 조건이 달라지는지 확인합니다. 이 기준을 통과한 다음 관련 콘텐츠·내보내기 검사와 필요한 의료·운영 확인을 진행합니다.

Google의 공식 안내도 사용자가 읽은 뒤 목적을 달성할 만큼 충분한 설명과 실질적 가치를 강조합니다. 이 보고서의 AEO·GEO 관련 판단은 그 원칙에 비춘 편집 평가이며, 검색 순위·AI 인용 증가·성능 개선을 측정하거나 보장한 결과가 아닙니다. [Google의 유용한 콘텐츠 안내](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)
