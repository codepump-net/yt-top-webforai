## 3. 별도로 남은 운영·승인·배포 확인

아래 항목은 위 54개의 집계에 추가로 합산하지 않는다. 실제 확인 기록이 필요한 운영 정보, 디자인 보완, 최신 변경분의 배포 상태를 추적한다.

| 관리 ID | 항목 | 현재 상태 | 확인·처리할 내용 | 완료 기준 |
|---|---|---|---|---|
| FOLLOW-01 | 원내 검사 시간·장비 운영 | 현재 원고와 이미지 일치 / 실제 운영 최종 확인 필요 | Troponin I 약 20분, 홀터 주로 72시간, CART BP Pro 24시간 안내가 현행 원내 운영과 일치하는지 확인 | 담당자의 확인일·확인 내용을 기록하고 차이가 있으면 본문·이미지 동시 수정 |
| FOLLOW-02 | 검진 예약·서류 발급기간 | 현재 원고와 이미지 일치 / 실제 운영 최종 확인 필요 | 일반 국가검진 예약 여부, 내시경 사전 예약, 일반채용 약 1일·공무원 약 1~2일·비자 약 2~3일 및 예외 조건 확인 | 담당자 확인 및 필요한 문구 수정 완료 |
| FOLLOW-03 | 최신 의료·운영 내용의 승인 기록 | 공식 자료 대조 완료 / 이번 변경분에 대한 승인 기록 없음 | 예방접종 대상·간격·금기, 내시경 준비·퇴실 안내, 감염병 안내 및 운영 정보에 대한 실제 검토 결과 기록 | 검토한 내용·버전·범위·확인자가 실제 승인 기록과 일치 |

| FOLLOW-05 | 최신 변경분의 운영 반영 | 로컬 검증 완료 / 이번 변경분 배포 미실시 | 배포 시 최신 이미지·본문 반영 후 운영 URL, 캐시, 원본 열기 확인. 검색 공개로 전환할 경우 현행 승인 검사 조건도 충족 | 배포한 버전과 실제 응답이 일치하고 운영 확인 기록 존재. 현재 로컬 출력은 review/noindex |

FOLLOW-01·02는 현재 안내가 틀렸다는 판정이 아니다. 원고와 이미지의 일치는 확인했으며 실제 원내 업무 기준에 대한 새 확인 기록이 남아 있지 않다는 의미다.

FOLLOW-03은 개발자가 의료 승인을 생성하는 작업으로 처리하지 않는다. 공개 전환 여부는 실제 검토 기록과 기존 production 검증을 따른다. 이번 자료 반영 작업에서 운영 배포나 검색 공개 전환을 실행하지 않았다.

장기·심전도 파형·장비 그림은 주제를 설명하는 일러스트다. 해부학 교육자료나 의료기기 사용설명서 수준의 정확성은 검증 범위에 포함되지 않았으며, 별도 용도로 사용할 때 확인할 한계로 남긴다.

- 새 원문을 교체할 때: 출처·이용 조건·문서 해시·실제 쪽수·전체 페이지 이미지·검사 기록을 함께 갱신한다.
