# 감염병 예방 가이드 공개 자료 검색·다운로드 결과

**후속 적용 완료:** 사용자의 자료 부족 해결 지시에 따라 아래 16쪽 공식 문서를 사이트에 반영하고 관련 7개 항목을 검증했다. [최종 결과](infection-resolution.ko.md). 아래는 다운로드 당시의 기록이며, 미연결·판정 유지라는 문장은 당시 상태를 뜻한다.

확인일: 2026-09-29. 사용자 질문에 따라 지정 제목과 병원 공식 채널, 현재 공지의 출처를 실제로 조회하고 공개 PDF를 내려받았다.

커밋 시 로컬 조사용 `output/`·`tmp/`는 제외했다. 아래 링크는 저장소에 포함한 16쪽 PDF 또는 공식 다운로드 주소로 연결한다. 당시 로컬 파일명·해시는 확보 증거에 보존한다.

## 1. 결과

**공식 예방 안내 자료는 내려받을 수 있으며 PDF 3개를 확보했다.** 현재 plan의 ‘첨부 PDF 15쪽’과 동일한 파일은 이번 검색 범위에서 특정하지 못했다. 다음 파일들은 찾은 공식 자료의 제목·분량 그대로 보관했다.

세 파일 모두 실제 HTTP 200 응답과 PDF 파일 서명을 확인했다. `pdfinfo`로 쪽수를 확인하고 다운로드 바이트·SHA-256을 기록했다. 카드뉴스 7쪽 전체와 다른 두 PDF의 첫 페이지를 렌더링해 제목·구성을 확인했다. 보도자료는 전체 텍스트를 추출해 16쪽의 구성도 확인했다. 전문 의료 검수나 통계 재분석을 수행한 것은 아니다.

원본 PDF 바이트를 그대로 저장했으며 15쪽으로 편집하거나 합치지 않았다. 이 파일들은 사용자 검토용 다운로드 자료이고 웹사이트에는 아직 연결하지 않았다.

## 2. 예방 안내 자료의 내용

- **7쪽 카드뉴스:** 표지, 해외여행, 호흡기 감염병, 수인성·식품매개감염병, 진드기 매개 감염병, 모기 매개 감염병, 마무리 안내로 구성된다. 게시일은 2026.9.21., 게시물 최종 수정일은 9.22.로 표시된다. [공식 게시물](https://www.kdca.go.kr/kdca/2853/subview.do?enc=Zm5jdDF8QEB8JTJGYmJzJTJGa2RjYSUyRjQ1JTJGMzEyNzAzJTJGYXJ0Y2xWaWV3LmRvJTNG).
- **16쪽 보도자료:** 본문 1~10쪽과 붙임 11~16쪽이다. 붙임은 해외여행·식품매개 감염병 예방 포스터, 진드기 매개 감염병 설명·리플릿, 모기 매개 감염병 카드뉴스다. 첫 페이지의 보도시점은 2026.9.20. 12:00, 배포시점은 9.18. 14:00이며 웹 게시물 제목에는 9.21. 조간으로 표기되어 있다. [공식 PDF](https://www.kdca.go.kr/bbs/kdca/42/309808/download.do).
- **38쪽 통계:** 현재 감염병 공지에 연결된 출처와 같은 바이트·해시다. 첫 페이지에 제19권 제36호·2026.9.17.과 2026년 37주차 보고 현황(9.12. 기준)이 표시된다. 문서 호수와 통계 주차가 다르므로 파일명만으로 주차를 판단하지 않았다.

## 4. 원래 체크리스트와의 관계

- 공개 자료를 직접 찾아 가져오는 작업은 가능하며 이번에 수행했다.
- 기존 특정 15쪽 첨부를 그대로 게시하는 요구의 자료 식별은 아직 해결되지 않았다. INF-02~06, BOARD-11, VERIFY-02의 판정은 갱신하지 않았다.
- 찾은 공식 자료를 사용하도록 요구 범위를 변경한다면 실제 제목·쪽수·발행 시점에 맞춰 원고와 체크리스트를 변경해야 한다. 기존 15쪽 원문을 확보한 것으로 처리하지 않는다.
- 2026-09-29 추가 확인: 16쪽 보도자료의 [공식 게시물](https://www.kdca.go.kr/kdca/2848/subview.do?enc=Zm5jdDF8QEB8JTJGYmJzJTJGa2RjYSUyRjQyJTJGMzEyNjYwJTJGYXJ0Y2xWaWV3LmRvJTNG)은 공공누리 **자유이용(제0유형)**으로 표시되어 있다. [유형 안내](https://www.kogl.or.kr/info/licenseType0.do)는 공유·변경·영리 목적 이용을 허용한다. 예방 가이드의 대체 원문 후보로 사용할 수 있으며, 실제 게시 시 출처와 발행 시점을 함께 표시하는 구성이 적절하다.
- 7쪽 카드뉴스의 [공식 게시물](https://www.kdca.go.kr/kdca/2853/subview.do?enc=Zm5jdDF8QEB8JTJGYmJzJTJGa2RjYSUyRjQ1JTJGMzEyNzAzJTJGYXJ0Y2xWaWV3LmRvJTNG)은 공공누리 **출처표시·상업적 이용금지·변경금지(제4유형)**로 표시되어 있다. [유형 안내](https://www.kogl.or.kr/info/licenseType4.do)에 따라 재게시 용도에 제약이 있으므로, 현재 제안은 공식 게시물 링크로 제공하는 방식이다.

### 대체 자료를 적용할 경우의 해결 범위

| 항목 | 적용할 작업 | 완료 판단 기준 |
|---|---|---|
| INF-02~03: 원문 전체·순서·잘림 없는 표시 | 확보한 16쪽 PDF를 페이지별 이미지로 변환하고 1~16쪽을 순서대로 게시 | 전체 16쪽과 PDF를 대조해 누락·중복·잘림 확인 |
| INF-04: 확대 열람 | 각 페이지를 확대해서 볼 수 있도록 연결 | 데스크톱·모바일 확대 동작과 글자 가독성 확인 |
| INF-05: 같은 원본 PDF 제공 | 화면 이미지의 출처인 16쪽 PDF를 다운로드 대상으로 연결 | 다운로드 파일의 쪽수·SHA-256 일치 확인 |
| INF-06: 원문과 보조 설명의 관계 | 원문 16쪽 전체와 통계·예방 안내의 출처·기준일을 구분 | 요약이 원문을 대신하지 않고 설명의 의미가 출처와 일치 |
| BOARD-11·VERIFY-02: 공지 상세·완료 검증 | 출처·발행일·첨부 연결 및 완료 검사를 실제 사용 문서에 맞춰 수정 | 콘텐츠 검사·내보내기·관련 브라우저 검사 통과 |

이는 **‘지정 첨부 15쪽’에서 ‘확보한 질병관리청 보도자료와 붙임 16쪽’으로 대체하는 경우**의 해결 방안이다. 원래 문서와 동일함을 입증한 것이 아니므로, 대체 사실과 변경한 수용 기준을 작업 기록에 남겨야 한다. 9월 17일 발간 통계와 9월 21일 조간용 예방수칙 자료의 날짜도 구분해야 한다. 현재는 적용 가능성을 확인한 단계이며, 웹페이지와 체크리스트 완료 판정은 변경하지 않았다.
