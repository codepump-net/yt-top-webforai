# 충돌 및 주의사항

1. **적용 순서를 바꾸지 마십시오.** 공지사항·지지치료 패치를 먼저, 고해상도 이미지·공식 채널 패치를 나중에 적용해야 합니다.
2. 첫 번째 모듈은 `web/public/assets/hero-cancer-support.webp`를 복사하지만, 두 번째 모듈이 페이지 대표 이미지를 고해상도 PNG 원장으로 바꿉니다. 최종 화면은 고해상도 PNG를 사용해야 합니다.
3. 기존 이미지 URL을 그대로 재사용하면 브라우저나 CDN 캐시 때문에 흐린 파일이 계속 보일 수 있습니다. `*-hq-original.png` 새 이름을 유지하십시오.
4. 공지사항 조회수는 정적 사이트만으로 전체 사용자 누적값을 저장하지 못합니다. 외부 카운터를 연결하지 않은 상태에서 브라우저별 값을 실제 조회수로 표시하지 마십시오.
5. 수원시 대상포진·경기도 학생 인플루엔자 공지에서 영통탑내과가 해당 사업의 지정 참여기관인지 확인되기 전에는 본원 지원접종 가능을 단정하지 마십시오.
6. 감염병 PDF 원문 이미지에는 원본의 문구와 표기가 포함되어 있습니다. 페이지를 임의 수정하거나 일부만 떼어 통계 의미를 바꾸지 마십시오.
7. 기존 `sameAs` 값이 있다면 덮어쓰지 말고 세 공식 채널을 중복 없이 병합하십시오.
8. 사이트에 같은 `<OfficialChannels>`가 한 화면에 중복 출력되지 않도록 기존 단독 링크와 새 컴포넌트를 함께 점검하십시오.
