# 통합 적용 순서

## 0. 사전 준비

1. 현재 저장소를 백업합니다.
2. 새 브랜치를 만듭니다.
3. 현재 빌드가 정상인지 확인합니다.
4. 실제 운영 배포 전에 `review/noindex` 상태를 유지합니다.

## 1. 자동 통합 적용

```bash
node /패키지절대경로/03_통합스크립트/apply-all-2026-09-29-latest.mjs /저장소절대경로
```

적용 순서는 고정되어 있습니다.

1. 공지사항 게시판·지지치료 명칭·감염병 이미지 패치
2. 원본화질 이미지·공식 채널 패치

두 번째 패치를 마지막에 적용해야 암환자 지지치료 배너를 포함한 대표 이미지가 고해상도 PNG 경로를 사용합니다.

## 2. UI 연결

자동 스크립트가 데이터와 컴포넌트를 복사한 뒤 다음을 실제 레이아웃에 연결합니다.

### 공식 채널

```tsx
import { OfficialChannels } from '@/components/ytop-visuals/OfficialChannels';
```

홈페이지 방문 안내 영역:

```tsx
<OfficialChannels variant="visit" />
```

전역 푸터:

```tsx
<OfficialChannels variant="footer" />
```

### 구조화 데이터

기존 MedicalClinic 또는 Organization JSON-LD의 `sameAs`에 다음 파일의 URL을 병합합니다.

```text
content/organization-sameas.json
```

### 고해상도 대표 이미지

기존 대표 이미지 렌더러를 패키지의 `ClinicPageImage.tsx`와 연결합니다. `object-fit: cover`로 자르지 않고 원본 비율을 유지합니다.

### 본문 안내도

패키지의 `InlinePageFigures.tsx`를 본문 블록 렌더러에 연결합니다.

## 3. 빌드

```bash
cd /저장소절대경로/web
npm ci
npm run build
```

- GitHub Pages/CDN 캐시 무효화

- 공식 채널 외부 링크 확인
