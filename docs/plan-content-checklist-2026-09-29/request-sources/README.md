# 영통탑내과 2026-09-29 최신 대화내용 블로그 통합 이식 패키지

이 패키지는 2026년 9월 29일에 확정한 최신 수정사항을 한 번에 다시 이식하기 위한 통합본입니다.

## 포함된 수정

1. 상단 메뉴에 `공지사항` 독립 메뉴 추가
2. 공지사항을 번호·제목·게시일·조회수·검색·분류·페이지 이동이 있는 게시판 구조로 변경
3. `암환자 지지진료`와 관련 표현을 `암환자 지지치료`로 통일
4. 2026–2027절기 인플루엔자 국가예방접종 일정을 HTML 표로 추가
5. 감염병 공지 제목을 `질병관리청 최신 데이터(9.17 기준)로 보는 우리 가족 감염병 예방 가이드`로 고정
6. 업로드된 감염병 PDF 15쪽을 순서대로 원문 이미지로 게시
7. 카테고리 배너와 안내도 17장을 최초 원본 PNG 화질로 교체
8. 병원 홈페이지·네이버 블로그·인스타그램 공식 링크 추가
9. Organization/MedicalClinic 구조화 데이터의 `sameAs`에 공식 채널 연결

## 가장 쉬운 적용

저장소를 백업하고 새 작업 브랜치를 만든 뒤, 패키지 루트에서 실행합니다.

```bash
node 03_통합스크립트/apply-all-2026-09-29-latest.mjs /저장소절대경로
```

빌드합니다.

```bash
cd /저장소절대경로/web
npm ci
npm run build
cd ..
```

기본 검증:

```bash
node /패키지절대경로/03_통합스크립트/verify-all-2026-09-29-latest.mjs /저장소절대경로
```

실제 UI 연결까지 엄격히 검사:

```bash
node /패키지절대경로/03_통합스크립트/verify-all-2026-09-29-latest.mjs /저장소절대경로 --strict-ui
```

## 수동으로 반드시 확인할 UI 연결

- 홈페이지 `진료시간·오시는 길` 영역에 `<OfficialChannels variant="visit" />`
- 전역 푸터에 `<OfficialChannels variant="footer" />`
- Organization/MedicalClinic JSON-LD의 `sameAs`에 `content/organization-sameas.json` 병합
- 공지사항이 데스크톱·모바일 상단 메뉴의 마지막 독립 항목인지 확인
- 감염병 공지에 15개 원문 이미지가 1쪽부터 15쪽까지 순서대로 표시되는지 확인
- 대표 이미지 요청 경로가 `.webp`가 아니라 `-hq-original.png`인지 확인
- 브라우저 캐시와 CDN 캐시를 비운 뒤 화질 확인
