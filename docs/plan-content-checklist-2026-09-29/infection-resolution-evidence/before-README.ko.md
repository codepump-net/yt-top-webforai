## 1. 범위와 판정 방식

대상은 용어·제목·본문·공지·이미지·공식 채널과 이를 환자가 찾고 읽는 기능이다. 원본 PNG의 실제 표시 경로, 공식 채널 `sameAs`, 모바일 동작, 콘텐츠 검증은 최종 결과를 확인하는 기준으로 포함한다.

사용자 지시에 따라 패키지 설치·복사, 자동 적용 스크립트, 두 패치의 적용 순서, 특정 패키지 컴포넌트 사용, 패키지 전용 검증 명령은 작업 범위에서 제외한다. 현재 코드에 맞는 방법으로 동일한 콘텐츠 결과를 구현하면 된다.

기준 자료는 로컬 작업 트리와 기존 정적 출력물이다. 기준 커밋은 `92528ee0f76a8fe2f466484a81e05cb19195efc1`이며, `plan/`의 새 문서는 아직 커밋되지 않은 작업 트리 파일을 읽었다. 최초 조사에서는 의료 일정·외부 응답을 다시 확인하지 않았다. 이후 9월 29일 개발 과정에서 인플루엔자 일정·공식 채널·기존 원문 링크를 확인했으며 [실제 결과](work-results.ko.md)에 근거를 기록했다.

| 표시 | 의미 |
|---|---|
| 원문 요구 | `plan/`에 명시된 환자 화면·콘텐츠 요구 |
| 보완 기준 | 명시된 요구를 빠짐없이 확인하기 위해 구체화한 편집·검수 기준 |
| 기존 기준 | 프로젝트의 환자 콘텐츠 정책과 기존 동작을 보존하는 기준 |
| 추가 확인 | 문서에 명시되지 않은 발견 사항. 별도 판단 없이 필수 신규 작업으로 확대하지 않음 |

결과 상태는 `미검증 / 충족 / 부분 충족 / 미충족 / 확인 필요`를 사용한다. 이미 일부 구현된 기능도 변경 이후 재확인하기 전에는 체크하지 않는다. 자료나 편집 결정이 필요한 항목은 그 항목에만 `확인 필요`를 기록하고, 독립적으로 진행할 수 있는 작업은 계속한다.

## 6. 감염병 예방 가이드

지정 제목: **질병관리청 최신 데이터(9.17 기준)로 보는 우리 가족 감염병 예방 가이드**.

- [x] **CHANNEL-07** 세 링크가 실제 해당 채널로 연결되고 화면에 표시한 주소와 구조화 데이터의 주소가 일치한다. **확인:** 실제 이동·리디렉션 도착지·확인일 기록. 로그인 요구와 잘못된 주소·삭제된 계정은 구분해 기록. *(보완 기준)*

## 9. 내용의 정확성과 기존 안내 보존

근거: `충돌및주의사항.md`와 [환자용 콘텐츠 기준](../patient-content-policy.ko.md).

- [x] **SAFE-01** 수원시 대상포진·경기도 학생 인플루엔자 두 글 모두, 본원이 해당 사업의 지정 참여기관인지 확인된 근거 없이 지원접종 가능을 단정하지 않는다. **확인:** 두 글의 최종 문장과 사업별 근거. 현재는 참여 여부·예약 문의 문구가 있으며 그대로 유지해도 이 기준을 충족할 수 있음.
- [x] **SAFE-02** 출처·확인일·검토자 표시는 실제 근거와 일치한다. **확인:** 공지 6편의 출처와 날짜 대조. 모의 검증 보고서나 코드 검사 통과를 의료 승인으로 표시하지 않음. *(기존 기준)*
- [x] **SAFE-03** 기존 홈페이지의 휴진·진료 소식 공지 채널과 사례 원문 링크 접근이 유지된다. **확인:** 기존 원문 링크를 실제로 열고 공지 개편이 원 게시 채널을 대체한 것으로 안내하지 않는지 읽기. 신규 공지 상세는 이번 6개 환자 안내의 범위로 정리하고 과거 폐기한 복제 공지·사례를 복구하지 않음. *(기존 기준)*
- [x] **SAFE-04** 의료·운영 검토가 완료되었다는 실제 근거가 생기기 전에는 `review/noindex`를 유지한다. **확인:** 최종 출력의 색인 설정과 기존 승인 검증. 화면의 문구 개선·기능 완료를 검색 공개 승인으로 간주하지 않음.

## 10. 작업 후 최종 확인

여기의 검증은 현재 저장소의 최종 콘텐츠와 화면을 확인하는 작업이다. 패키지 전용 검증 도구 사용은 요구하지 않는다.

- [x] **VERIFY-01** 변경한 콘텐츠에 대해 기존 콘텐츠 검사·정적 출력 검사·빌드가 통과한다. **확인:** 현재 저장소의 `content:validate`, `build`, `audit:static` 등 적용한 검사와 실제 결과 로그. 원문과 소스 정책에 맞게 검사를 조정하되 기존 출처·이미지 무결성·승인 경계를 약화하지 않음.
- [ ] **VERIFY-02** 데스크톱·모바일에서 메뉴, 게시판, 표, 원문 이미지, 원본 보기, 공식 채널을 직접 확인한다. **확인:** 사용한 화면 폭과 페이지별 증거. 기존 키보드 이동·확대창 닫기·포커스 복귀도 보존. *(원문 요구·기존 UI 기준)*
- [x] **VERIFY-03** 새로고침 후 실제 제공 파일이 최신 원본 PNG와 최신 콘텐츠인지 확인한다. **확인:** 캐시를 비활성화하거나 갱신한 상태의 실제 요청·화면. 운영/CDN 캐시는 배포 확인 단계에 해당하는 경우 기록하며 이번 문서는 배포를 수행했다는 뜻이 아님.
- [x] **VERIFY-04** 변경 파일 목록, 작업 전후 결과, 실행한 검사, 남은 경고·확인 필요 사항을 결과 기록표에 남긴다. **확인:** 모든 검수 ID의 실제 결과와 증거가 채워짐. 미충족 항목을 완료 처리하거나 모의 검증 결과를 실제 사이트 결과로 전용하지 않음.

## 12. 완료 판정과 증거 기록

작업 후에는 [결과 기록표](work-results.ko.md)의 모든 검수 ID에 `실제 확인한 내용`, `판정`, `확인일·확인자`, `증거`, `남은 문제`를 기록한다. 현재 판정과 증거는 결과 기록표에 반영했다. 미선택 항목은 감염병 원문 15쪽 게시 또는 해당 문서의 검증이 남아 있다.

특히 다음 전수 목록이 완료되어야 해당 그룹을 충족으로 판정한다.

- 텍스트 20곳과 배너 내부 용어: 이전 표현·최종 표현 대조.
- 공지 6편: 실제 상세 주소·제목·출처·날짜·링크 확인.
- 대표 배너·안내도 17개: 원본·요청 주소·크기·비율·클릭·ALT·배치 확인.
- 감염병 15쪽: 순서·페이지 전체·원문 일치·확대·PDF 대응 확인.
- 공식 채널 3개: 홈·푸터·병원안내의 표시와 `sameAs` 확인.

검증 화면·로그·문서 링크는 내부 기록에 남긴다. 공개 사이트에는 환자에게 필요한 콘텐츠와 실제 출처만 표시한다.
