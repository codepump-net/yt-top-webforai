# 전체 체크리스트의 미해결 항목

정리일: 2026-09-29. 이식 패키지 관련 작업은 제외한다. 기존 [54개 검수표](README.ko.md), [작업 결과](work-results.ko.md), [이미지 정확성 검토](image-accuracy.ko.md)를 대조했다.

원문을 준비하기 위한 구체적인 단서는 [plan 원문·원본 언급 전수 조사](original-material-references.ko.md)를 확인한다. PDF 파일명·URL·표지 제목은 plan에 기재되어 있지 않다.

**외부 자료 확보:** [공식 PDF 3개 다운로드 결과](infection-source-retrieval.ko.md). 자료별 실제 분량은 7쪽·16쪽·38쪽이며, 기존 특정 15쪽 요구의 판정은 유지한다.

## 1. 현재 집계

| 범위 | 충족 | 부분 충족 | 미충족 | 미완료 합계 |
|---|---:|---:|---:|---:|
| 기존 콘텐츠 체크리스트 54개 | 47 | 2 | 5 | **7** |

미완료 7개는 모두 **요청된 감염병 원문 15쪽의 미게시**와 연결되어 있다. 기존에 연결된 통계 PDF는 38쪽으로 확인되어 요청된 15쪽 문서의 대체 자료로 판정하지 않았다.

이번에 `verify-plan-content.mjs`를 다시 실행한 결과, 고해상도 PNG 17개는 확인됐고 감염병 원문은 0쪽으로 보고됐다. 실패 사유는 해당 원문 및 같은 PDF의 미등록 1건이다. [이번 검사 결과](outstanding-evidence/plan-content-completion.json).

## 2. 기존 체크리스트에서 남은 7개

| 검수 ID | 상태 | 아직 해결되지 않은 내용 | 남은 작업 | 완료 판정 기준 |
|---|---|---|---|---|
| INF-02 | 미충족 | 요청한 15쪽 원문 이미지가 게시되지 않음 | 요청 대상 원문을 식별·확보하고 1~15쪽을 이미지로 등록·게시 | 총 15개가 원래 순서로 표시되고 누락·중복이 없음 |
| INF-03 | 미충족 | 문구·수치·단위·기준일과 페이지 잘림을 원문과 대조하지 못함 | 15쪽 각각을 원문과 나란히 비교하고 쪽별 기록 작성 | 원문 전체 내용이 보존되며 표·각주·가장자리가 잘리지 않음 |

| BOARD-11 | 부분 충족 | 공지 6편의 기존 내용은 보존했으나 감염병 글의 원문 보강이 남음 | 위 INF 작업 후 6편의 대상·조건·준비사항·출처를 최종 대조 | 감염병 글까지 포함해 요청 내용의 누락이 없음 |
| VERIFY-02 | 부분 충족 | 메뉴·게시판·표·채널·PNG 17개는 확인했으나 감염병 15쪽 화면은 미검증 | 원문 게시 후 모바일·데스크톱·확대·원본 PDF·키보드 동작 검사 | 해당 원문까지 포함한 실제 화면 증거와 검사 결과 기록 |

INF-04의 확대 기능은 구현되어 있다. 실제 자료를 연결한 뒤 15개 전부를 검증해야 완료된다. 자료 확보만으로 위 7개가 자동 완료되는 것은 아니다.

## 3. 최근 검토에서 남은 확인·보완 사항

아래 항목은 위 54개의 집계에 추가로 합산하지 않는다. 실제 확인 기록이 필요한 운영 정보, 디자인 보완, 최신 변경분의 배포 상태를 추적한다.

| 관리 ID | 항목 | 현재 상태 | 확인·처리할 내용 | 완료 기준 |
|---|---|---|---|---|
| FOLLOW-01 | 원내 검사 시간·장비 운영 | 현재 원고와 이미지 일치 / 실제 운영 최종 확인 필요 | Troponin I 약 20분, 홀터 주로 72시간, CART BP Pro 24시간 안내가 현행 원내 운영과 일치하는지 확인 | 담당자의 확인일·확인 내용을 기록하고 차이가 있으면 본문·이미지 동시 수정 |
| FOLLOW-02 | 검진 예약·서류 발급기간 | 현재 원고와 이미지 일치 / 실제 운영 최종 확인 필요 | 일반 국가검진 예약 여부, 내시경 사전 예약, 일반채용 약 1일·공무원 약 1~2일·비자 약 2~3일 및 예외 조건 확인 | 담당자 확인 및 필요한 문구 수정 완료 |
| FOLLOW-03 | 최신 의료·운영 내용의 승인 기록 | 공식 자료 대조 완료 / 이번 변경분에 대한 승인 기록 없음 | 예방접종 대상·간격·금기, 내시경 준비·퇴실 안내 및 운영 정보에 대한 실제 검토 결과 기록 | 검토한 내용·버전·범위·확인자가 실제 승인 기록과 일치 |
| FOLLOW-04 | 이미지 속 병원 로고 통일 | 선택 보완 / 미수정 | 병원명은 맞지만 엠블럼의 선·비례·장식이 이미지마다 다름. 정확한 CI 통일을 진행할 경우 기존 공식 로고를 적용 | 대상 이미지의 로고가 공식 원본과 일치함을 확인. 기존 요청의 필수 미충족으로 추가 집계하지 않음 |
| FOLLOW-05 | 최신 변경분의 운영 반영 | 로컬 검증 완료 / 이번 변경분 배포 미실시 | 배포 시 최신 이미지·본문 반영 후 운영 URL, 캐시, 원본 열기 확인. 검색 공개로 전환할 경우 현행 승인 검사 조건도 충족 | 배포한 버전과 실제 응답이 일치하고 운영 확인 기록 존재. 현재 로컬 출력은 review/noindex |

FOLLOW-01·02는 현재 안내가 틀렸다는 판정이 아니다. 원고와 이미지의 일치는 확인했으며 실제 원내 업무 기준에 대한 새 확인 기록이 남아 있지 않다는 의미다.

FOLLOW-03은 개발자가 의료 승인을 생성하는 작업으로 처리하지 않는다. 공개 전환 여부는 실제 검토 기록과 기존 production 검증을 따른다. 이번 표 정리를 위해 배포나 공개 전환을 실행하지 않았다.

장기·심전도 파형·장비 그림은 주제를 설명하는 일러스트다. 해부학 교육자료나 의료기기 사용설명서 수준의 정확성은 검증 범위에 포함되지 않았으며, 별도 용도로 사용할 때 확인할 한계로 남긴다.

## 4. 완료되어 미해결 목록에서 제외한 사항

- PNG 17개 신규 제작과 실제 파일 연결, 원본 열기·확대·모바일 표시.
- 암환자 이미지의 `지지치료` 문구, 신장 배너 제목과 콩팥 그림.
- 검사 장비·혈압 커프 장면·폐렴구균 명칭·예방접종 일정표 4행 보완.
- 수정 후 콘텐츠 검사, 단위 검사 82개, 관련 브라우저 검사 7개, 135경로 review 빌드·출력 검사. 이는 직전 이미지 수정 후 검사 기록이며 이번 표 정리에서 다시 실행한 것으로 표시하지 않는다.
- 지역사업 참여를 단정하지 않는 안내, 미집계 조회수의 `—` 표시는 기존에 결정·반영한 상태다.

## 5. 판정 기록 정정

이전 판정 JSON에는 `충족`으로 바뀐 TERM-04, IMG-01, IMG-02에도 과거의 ‘최초 원본 PNG 또는 요청된 15쪽 PDF 미확보’ 사유가 남아 있었다. [현재 판정 JSON](requirement-results.current.json)에서는 완료된 항목의 이 사유를 제거하고, 미완료 7개에는 감염병 원문 관련 사유만 기록했다. 과거 파일은 이력으로 보존한다. 집계는 47/2/5로 동일하다.

## 6. 처리 순서

1. 요청한 감염병 원문 15쪽을 식별·확보한다.
2. 15쪽 이미지와 같은 원본 PDF를 게시하고 쪽별 내용·확대·화면 검증을 수행한다.
3. 위 검증 근거로 INF-02~06, BOARD-11, VERIFY-02를 갱신한다.
4. 원내 운영·의료 검토 결과를 기록하고 필요한 수정에 반영한다. 이 확인은 원문 게시 작업과 독립적으로 진행할 수 있다.
5. 배포를 진행할 때 대상 모드의 검증을 통과하고 운영 환경에서 최신 변경분을 확인한다.
