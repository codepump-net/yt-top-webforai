# plan 문서의 원문·원본 자료 언급 전수 조사

커밋 보관용 요청 문서는 `request-sources/`에 초기 해시와 동일하게 보존했다. 원래 작업 폴더의 `plan/` 추가·삭제 상태는 변경하지 않았다.

**후속 완료 기록:** [공식 자료 16쪽 적용·자료 부족 해결](infection-resolution.ko.md). 사용자 후속 지시에 따른 대체 기준으로 현재 체크리스트는 54/0/0이다. 아래 원문 인용·이전 시점의 판단과 이미지 검수 이력은 보존한다.

조사일: 2026-09-29. 대상: 현재 `plan/` 폴더의 Markdown 문서 **7개 전체**. 각 문서를 처음부터 끝까지 읽고 `원문`, `원본`, `PDF`, `첨부`, `업로드`, `15쪽`, `15개`, 고해상도 PNG 및 관련 경로를 대조했다. plan 문서 자체는 수정하지 않았다.

**후속 검색:** [공개 예방 가이드 검색·다운로드 결과](infection-source-retrieval.ko.md). 공식 PDF 3개(7쪽·16쪽·38쪽)를 실제 확보했으며 요청된 15쪽 자료와의 동일성은 미확인이다.

## 1. 어떤 자료를 뜻하는가

| 구분 | plan에서 지칭하는 자료 | 현재 준비 필요 여부 |
|---|---|---|
| 감염병 원문 | 감염병 예방 가이드 공지에 게시할 **기존 업로드/첨부 PDF의 15쪽**과 이를 그대로 보여주는 페이지 이미지 | 현재 추가 준비 불필요. 후속 지시에 따라 공식 16쪽 원문을 적용·검증함. 기존 15쪽 식별 조사는 이력으로 보존 |
| 이미지 원본 | 대표 배너·안내도 **17개의 최초 생성 PNG** | 사용자가 고해상도 재제작 요청으로 정정했고 신규 제작·반영을 완료함. 과거 PNG 제공은 현재 선행 조건이 아님 |

**핵심 결론:** plan은 감염병 자료를 ‘업로드한 PDF’ 또는 ‘첨부 PDF 15쪽’으로 지칭하지만, **PDF 파일명·다운로드 URL·표지 제목·문서 번호를 제시하지 않는다.** 따라서 plan 문서만으로 특정 PDF를 하나로 확정할 수 없다.

## 5. 현재 저장소 자료와의 관계 및 이전 설명 정정

- 현재 `plan/`에는 Markdown 7개와 시스템 메타파일 `.DS_Store`가 있으며, PDF·이미지·압축 패키지 첨부는 없다.
- 저장소 파일명 조사에서 확인한 감염병 통계 자료는 `.local/afternoon-update/PHWR_Supple_19-36.pdf`다. 종전 검증에서 38쪽으로 기록되었다.
- 현재 `content/notices.json`의 감염병 공지에는 질병관리청 통계 링크와 위 통계 PDF에 대응하는 외부 첨부 링크가 있다. 이 정보는 **현재 구현에서 확인한 정보**이며 plan에 적힌 PDF 파일명이나 URL이 아니다.
- **이전의 ‘요청한 PDF와 다른 문서임을 확인했다’는 표현은 정정한다.** 정확한 상태는 ‘현재 확인된 통계 PDF는 38쪽이고, plan에서 지칭한 첨부 15쪽 자료와의 동일성은 확인하지 못했다’이다. 쪽수 차이만으로 내용상의 관계까지 확정할 수 없다.
- 요청된 15쪽이 별도 제작 안내문인지, 다른 자료를 바탕으로 편집한 자료인지도 현재 문서만으로 확정할 수 없다.

과거 첨부가 존재하지 않는다면 원문 보존이라는 기존 요청을 수행할 자료가 없는 상태다. 그때는 원하는 안내 내용을 새로 제작하는 것으로 범위를 바꿀지 정해야 하며, 새 제작물을 과거 원문으로 표시하지 않는다.
