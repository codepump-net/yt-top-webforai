## 공지별 편집 결정

- **분류:** 국가 HPV·폐렴구균·인플루엔자는 `예방접종`, 수원시 대상포진·경기도 학생 독감은 `지역 지원사업`, 감염병 자료는 `감염병 예방`이다. 태그는 각 글의 질환·대상·지역으로 구성했다.
- **중요 공지:** 현재 접종 절기의 대상별 날짜 확인을 돕기 위해 국가 인플루엔자 안내를 상단에 고정했다. 고정 여부는 `pinned`로 관리한다.
- **최초 게시일:** 6편의 최초 확인 가능한 공개 기록인 2026-09-28을 사용한다. [기존 배포 확인](../director-requirements-2026-09-27-afternoon/deployment.ko.md)의 00:50 KST, 커밋 `065db4a`가 근거다. 9월 29일은 상세 경로 개편일이며 원자료 발표일과 구분한다.
- **내용 확인일:** 인플루엔자는 실제 재확인한 2026-09-29, 나머지는 기존 2026-09-28을 보존했다. 변경하지 않은 공지의 확인일을 일괄 갱신하지 않았다.
- **조회수:** 실제 수집 데이터가 없어 `views: null`과 `—`를 표시한다. `0`과 미집계를 구분하며 로컬 저장 증가값·임의 누적값은 만들지 않았다. 숫자가 입력되면 목록·상세에서 같은 값을 표시한다.
- **지원 가능 여부:** 두 지역 지원사업의 본원 참여 여부는 확인되지 않았다. 기존 전화 확인 문구를 보존했다.
- **내용 보존:** 6편의 기존 문단·지원 조건·기간·첨부 링크를 유지했다. 새 상세 원고와 공지 원장이 달라지거나 미등록 상세가 추가되면 콘텐츠 검사가 실패한다.

## 원본 자료가 필요한 작업

| 필요한 자료 | 현재 확인한 파일 | 남은 작업 |
|---|---|---|
| 최초 생성 PNG 17개 | 모음판에서 잘라낸 400×225 배너, 240~280×300 안내도 WebP. 다른 과거 생성 PNG는 같은 원본이 아님 | 자산별 원본 대조, 지정 PNG 경로로 교체, 전체 내용·요청 주소·새로고침·원본 열기 확인 |
| 암환자 배너의 최종 원본 | 현재 그림 안에는 지지진료가 남아 있음 | 원본 확보 후 지지치료 문구와 원본 품질을 함께 확인 |
| 감염병 예방 가이드 15쪽 PDF | 기존 `PHWR_Supple_19-36.pdf`는 **38쪽**, 3,655,819바이트 | 실제 요청 원문 확인 후 15쪽 순차 이미지와 동일 PDF 제공·전수 대조 |

기존 통계 PDF의 SHA-256은 `26940a084103777bdc5b73a0a611a19571a547aba657207065e98e4b50ef5bf7`이다. 이 38쪽 자료 일부를 임의로 15쪽으로 잘라 대체하지 않았다. 현재 감염병 상세에는 기존 통계 요약과 해당 출처 링크가 남아 있으며, 요청된 원문 이미지가 게시되었다고 표시하지 않는다.

15쪽 순서·중복·자산 존재를 검사하는 원장 구조와 이미지/PDF 표시 기능은 준비했다. 실제 문서가 등록되면 PDF 헤더·파일 해시도 검사한다. 이 기능 준비는 원문 게시 완료 판정과 구분한다.

신장 배너의 콩팥 그림 위 `심장질환` 표기는 기존 자료의 추가 확인 사항이다. 최종 원본에서 함께 확인할 필요가 있다.
