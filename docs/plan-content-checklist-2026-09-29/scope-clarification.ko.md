# 이식 패키지 제외와 실제 수행 작업 확인

확인일: 2026-09-29. 사용자 재확인: “이식용 패키지는 논이슈로 처리하라고 했습니다. 혹시 별도로 작업한 것이 있습니까?”

## 1. 패키지 처리

**이식용 패키지는 논이슈·범위 제외다.** 제공·확보·설치·복사·자동 적용·패키지 전용 검증을 요구사항이나 자료 부족 사유로 집계하지 않는다. 패키지 확보를 요청하거나 해당 파일이 없다는 이유로 작업을 보류하지 않는다.

검토한 작업 기록에서 패키지 설치·통합 적용 작업은 수행하지 않았다. 현재 개발 파일에도 `apply-all-2026-09-29-latest.mjs`, `verify-all-2026-09-29-latest.mjs` 등의 패키지 전용 파일은 없다. 현재 plan 7개 파일의 SHA-256은 원문 조사 때 기록한 값과 같다. 패키지 자체를 작성하거나 배포하지 않았다.

`web/scripts/verify-plan-content.mjs`는 현재 사이트의 PNG·문서 파일을 확인하기 위해 작성한 검사다. 패키지의 `verify-all-2026-09-29-latest.mjs` 또는 `--strict-ui` 검사를 실행한 것으로 보고하지 않는다.

## 2. 이전 부분 충족 2개의 의미

| ID | 당시 부분 충족 사유 | 패키지와의 관계 | 현재 |
|---|---|---|---|
| BOARD-11 | 공지 6편 중 감염병 글에 원문 자료가 게시되지 않음 | 환자용 공지 콘텐츠 보강 항목. 패키지 설치 여부를 검사하지 않음 | 공식 자료 16쪽 게시 후 충족 |
| VERIFY-02 | 게시할 감염병 원문이 없어 실제 이미지 화면·확대를 검증하지 못함 | 실제 브라우저 결과 검사. 패키지 전용 검사 제외 | 16쪽 화면 검증 후 충족 |

당시 판정은 [변경 전 JSON](infection-resolution-evidence/before-requirement-results.current.json), 현재 판정은 [최신 JSON](requirement-results.current.json)에 있다. 패키지를 적용했기 때문에 충족으로 바꾼 것이 아니다.

## 3. 별도로 실제 수행한 작업

예방 자료를 가져올 수 있는지와 그 자료로 해결 가능한지에 대한 후속 대화, “자료부족 문제 모두 정확하게 해결해주세요”라는 지시에 따라 현재 사이트 코드에서 아래 작업을 수행했다.

| 작업 | 실제 반영 위치·결과 |
|---|---|
| 공식 예방수칙 자료 반영 | `web/public/assets/notice-documents/`에 원본 PDF 1개와 페이지 PNG 16개 추가 |
| 감염병 공지 보강 | `content/notices.json`, `content/pages.json`, `content/assets.json`에 원문·출처·날짜·첨부·이미지 등록 |
| 원문 표시·확대 | `notice-document.tsx`, `zoom-image.tsx`에서 전체 페이지와 원래 픽셀 크기 확대·스크롤·PDF 보기 제공 |
| 현재 사이트 검사 보완 | `infection-guide-source.mjs`, `patient-additions-contract.mjs`, `validate.mjs`, `verify-plan-content.mjs` 및 관련 테스트 수정·추가 |
| 검증과 기록 | 135경로 빌드, 단위 84개, 루트 브라우저 4개·프로젝트 경로 14개 통과. 수용 기준 변경과 전후 결과 기록 |

직전 자료 반영 작업에서 감염병 외 다른 공지 5편과 기존 이미지 자산은 변경 전 스냅샷과 동일하다. 기존에 개발한 용어 교정·공지 기능·이미지 17개 재제작 작업은 각각의 작업 기록에 남아 있다.

공식 16쪽 자료 적용은 별도의 콘텐츠 작업으로 수행했다. 최초 15쪽 문서 복구나 이식 패키지 적용으로 표현하지 않는다. 운영 배포는 수행하지 않았으며 로컬 review/noindex 상태다.

## 4. 이번 설명·문서 정정

과거 `implementation.ko.md`와 `final-review.ko.md`의 머리말에 47/2/5 수치를 “최신 상태”로 표시한 문장이 남아 있었다. 이를 과거 시점 기록으로 정정하고 현재 결과로 연결했다. 현재 검수표에는 이식 패키지를 명시적으로 논이슈로 기록했다. 이번 확인에서는 공개 페이지·기능·자산을 수정하지 않았다.
