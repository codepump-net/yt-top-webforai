# 고해상도 이미지 17개 재제작·반영 결과

**후속 완료 기록:** [공식 자료 16쪽 적용·자료 부족 해결](infection-resolution.ko.md). 사용자 후속 지시에 따른 대체 기준으로 현재 체크리스트는 54/0/0이다. 아래 원문 인용·이전 시점의 판단과 이미지 검수 이력은 보존한다.

2026-09-29. **배너 12개와 안내도·일정표 5개를 모두 새로 그려 사이트에 반영했다.** 이식 패키지는 사용하지 않았다. 로컬 review 출력이며 운영 배포는 수행하지 않았다.

> 이 문서는 최초 재제작 시점의 기록이다. 이후 정확성 검토에서 4개 이미지를 수정했다. 현재 파일 해시·검증 결과와 남은 확인 사항은 [후속 정확성 검토](image-accuracy.ko.md)를 따른다. 아래 용량·성능 수치는 최초 재제작 당시 값이다.

## 1. 요청 해석 정정

사용자는 기존 원본 리소스가 없으며, 원본 화질 요청은 고해상도로 다시 그리라는 의미라고 정정했다. 앞선 작업에서 최초 PNG 파일 제공을 선행 조건으로 판단한 것은 잘못이었다. IMG-01은 **17개 고해상도 신규 제작**으로 수정했고, 이미지를 받을 때까지 기다리는 항목은 제거했다.

현재 PNG는 이번에 새로 제작한 마스터다. 과거 최초 PNG를 복구했다는 의미로 사용하지 않는다. 작은 참고 이미지의 디자인과 현재 환자 안내 문구를 바탕으로 내장 `image_gen`에서 각각 생성했다. 생성 결과를 확대·잘라내기·재압축하지 않고 바이트 그대로 보존했다.

- 생성 마스터: [assets/generated/redrawn-2026-09-29](../../assets/generated/redrawn-2026-09-29/README.ko.md)
- 실제 사이트 파일: `web/public/assets/clinic-visuals-hq/*-hq-original.png`
- 입력·수정 기록: [17개 프롬프트](../../assets/generated/redrawn-2026-09-29/prompts.json)
- 실제 크기·용량·해시·배치: [17개 전후 기록](redraw-evidence/assets.json)

## 3. 그림·문구 검수

17개 생성 결과를 각각 열어 제목, 브랜드, 작은 설명, 단계와 표를 읽고 잘림을 확인했다. 배너는 주제와 그림의 관계도 확인했다.

- 암환자 배너의 문구는 `암 치료 중 지지치료`다. 입원 침대·환자복·수액 장면을 외래 상담 장면으로 수정했다.
- 신장 배너의 제목과 ALT를 `신장질환`으로 맞췄다.
- 심장검사 안내의 응급 증상, 초기 정상 Troponin I 결과의 한계, 개별 검사 선택 문구를 보존했다.
- 내시경 준비와 검사 후 안내는 현재 HTML의 개별 금식·약 복용·활동 지침을 사용했다. 과거 작은 그림의 일률적 시간표를 다시 옮기지 않았다.
- 검진 안내의 다섯 단계와 발급기간 조건, 성인 예방접종 표의 아홉 행·접종 전 상담 문구를 HTML과 대조했다.
- 이 검수는 그림·문구·구현 대조다. 별도의 의료 승인이나 새로운 임상 검토를 받았다고 표시하지 않는다.

## 4. 구현과 재발 방지

- [이미지 원장](../../content/assets.json)에 17개의 새 경로, 실제 픽셀 크기·바이트·SHA-256과 생성 출처를 등록했다.
- [PNG 검사](../../web/scripts/redrawn-image-contract.mjs)는 실제 PNG 형식, 최소 픽셀 크기, 지정 공개/마스터 경로, 원본 바이트 일치와 개별 8 MB 상한을 검사한다. 다른 기존 이미지의 200 kB 제한은 유지한다.
- [콘텐츠 검사](../../web/scripts/patient-additions-contract.mjs)는 지정 PNG 17개를 필수로 확인하고 안내도·일정표의 내용 해시를 검사한다.
- [미리보기 서버](../../web/scripts/serve.mjs)에 PNG/PDF MIME을 추가했다. PNG의 실제 새 창 표시를 브라우저로 확인했고, PDF MIME은 임시 파일 응답으로 검사했다. 이 PDF 응답 검사가 감염병 원문 게시를 뜻하지는 않는다.
- 과거 모음판 가져오기와 HTML 안내도 렌더링 스크립트가 새 PNG를 작은 WebP로 덮어쓰지 못하게 했다.
- `npm run verify:plan`은 일반 review 빌드와 별도로 필수 요청의 완료 여부를 검사한다. 현재 PNG 17개는 통과하며 감염병 15쪽 미등록만 실패 사유로 남는다.

## 6. 체크리스트 최종 상태

**54개 중 충족 47개 · 부분 충족 2개 · 미충족 5개.** 최초 핵심 요청 9개 기준으로는 8개 충족, 감염병 PDF 게시 1개 미충족이다. 원문 체크리스트 42개는 35개 충족·5개 미충족·이식 절차 2개 제외다.

- 이번에 완료: TERM-04, IMG-01~07, 로컬 최신 PNG 확인인 VERIFY-03. 원래 충족했던 IMG-04·06·07도 새 그림으로 재검증했다.
- 부분 충족: BOARD-11, VERIFY-02. 감염병 원문이 게시되지 않아 해당 문서까지 포함한 확인은 남아 있다.
- 미충족: INF-02~06. 특정 15쪽 원문의 순차 게시·내용 보존·확대·같은 PDF 접근·원문을 임의 요약으로 대체하지 않는 요구다. 현재 연결된 공식 통계 PDF는 38쪽이므로 해당 원문으로 판정할 수 없다.

PNG 제작은 기존 리소스 제공 없이 완료했다. 감염병의 특정 원문을 보존하라는 요구를 새로 쓴 안내문으로 바꾸지는 않았다. 과거 검증 파일은 당시 기록으로 보존하고, 현재 판정은 [작업 결과표](work-results.ko.md)와 [새 판정 JSON](redraw-evidence/requirement-results.json)에 갱신했다.
