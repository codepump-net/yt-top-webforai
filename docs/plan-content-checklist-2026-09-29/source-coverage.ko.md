# plan 원문 요청 대조표

커밋 보관용 요청 문서는 `request-sources/`에 초기 해시와 동일하게 보존했다. 원래 작업 폴더의 `plan/` 추가·삭제 상태는 변경하지 않았다.

**최신 배포 전 검토:** [문구 수정 전후·전체 검증·배포 판단](predeploy-review.ko.md). 이식 패키지 논이슈를 제외한 54개 기준을 재확인했다.

**후속 완료 기록:** [공식 자료 16쪽 적용·자료 부족 해결](infection-resolution.ko.md). 사용자 후속 지시에 따른 대체 기준으로 현재 체크리스트는 54/0/0이다. 아래 원문 인용·이전 시점의 판단과 이미지 검수 이력은 보존한다.

2026-09-29. 현재 폴더의 문서 7개를 모두 읽었다. 중복된 요구는 같은 검수 ID로 묶고, 요구 문서 한 곳에만 있는 항목도 포함했다.

[상세 기준](README.ko.md) · [실제 결과 기록](work-results.ko.md) · [파일 해시와 작업 전 상태](baseline.json)

**후속 사용자 정정:** 이미지 관련 최초 원본 PNG 표현은 기존 리소스 제공을 기다리라는 뜻이 아니라 고해상도로 다시 그리는 요청이다. 원문 인용은 그대로 보존하고 현재 IMG-01 판정과 작업 결과에는 새 제작 기준을 적용한다. [정정·제작 결과](redrawn-images.ko.md).
