- **시술 후 시간표:** 원본의2~3시간·6~8시간 등의 기준점·적용 시술은 미확정입니다. 사용자의 비확대 지시에 따라 원본을 보존하고 모든 환자의 공통 지침으로 새로 쓰지 않았습니다.

- **지역 지원접종:** 수원시 대상포진·경기도 학생 독감 사업의 본원 참여 여부는 여전히 미확인입니다. 공식 사업 조건과 본원 가능 여부를 구분했습니다.
- **원본 이미지 제약:** 신장 배너의 원본 오기와 작은 글자의 해상도 한계는 그대로입니다. 안내도와 HTML이 완전히 동일하다고 보고하지 않습니다.
- **실제 의료·운영·언어 검토:** 개발자가 출처를 확인한 사실을 의료진 승인으로 바꾸지 않았습니다. 수정본의 검토자·검토일을 만들어 넣지 않았습니다.
